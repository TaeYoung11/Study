# DB N:1 1 정리

가장 흔한 테이블 관계인 **1:N(다대일) 관계**의 개념과, Django에서 이를 표현하는 `ForeignKey`, 그리고 실전 예제인 **댓글(Comment) 기능 구현**을 정리한 문서입니다.

---

## 1. Many to one relationships (N:1 관계)

* **N:1 관계:** 한쪽 테이블(N)의 여러 행이, 다른 쪽 테이블(1)의 하나의 행을 참조하는 관계
* 예: 여러 개의 **댓글(N)** 이 하나의 **게시글(1)** 에 달리는 경우

```sql
CREATE TABLE comments (
    id INTEGER PRIMARY KEY,
    content TEXT,
    article_id INTEGER,
    FOREIGN KEY (article_id) REFERENCES articles(id)   -- "N"쪽 테이블에 FK를 둠
);
```

* 관계를 표현하는 외래키(FK)는 항상 **N(여러 개)쪽 테이블**에 위치함 — "이 댓글이 어느 게시글 소속인지" 하나의 값만 저장하면 되기 때문

---

## 2. 관계 모델 참조 (Django ForeignKey)

```python
# models.py
class Article(models.Model):
    title = models.CharField(max_length=100)

class Comment(models.Model):
    article = models.ForeignKey(Article, on_delete=models.CASCADE)   # N:1의 "N"쪽에 정의
    content = models.CharField(max_length=200)
```

### `on_delete` 옵션

| 옵션 | 설명 |
| --- | --- |
| `CASCADE` | 참조하는 부모(Article)가 삭제되면, 관련된 자식(Comment)도 함께 삭제 |
| `PROTECT` | 자식이 남아있으면 부모 삭제를 막음 (예외 발생) |
| `SET_NULL` | 부모가 삭제되면 자식의 FK를 NULL로 설정 (FK에 `null=True` 필요) |

```python
comment = Comment.objects.get(pk=1)
comment.article          # 정참조: 댓글 -> 게시글 (FK로 바로 접근)
comment.article.title     # 참조를 이어서 게시글의 필드까지 접근 가능
```

## 3. 댓글 구현

```python
# views.py
def comment_create(request, article_pk):
    article = get_object_or_404(Article, pk=article_pk)
    comment_form = CommentForm(request.POST)
    if comment_form.is_valid():
        comment = comment_form.save(commit=False)   # 아직 DB에 저장하지 않고 인스턴스만 생성
        comment.article = article                     # 어떤 게시글의 댓글인지 지정
        comment.save()                                  # 이 시점에 실제 DB 저장
    return redirect("articles:detail", article_pk)
```

* `commit=False`: Form의 유효성 검증은 마쳤지만, 아직 DB에 저장되지 않은 모델 인스턴스만 얻어옴
* 이 방식을 사용하는 이유: 폼에는 없는 정보(`article`처럼 URL의 `pk`로부터 얻어야 하는 값)를 **저장 직전에 추가로 채워 넣기 위해서**

```html
<!-- 게시글 상세 페이지에서 댓글 목록과 작성 폼을 함께 표시 -->
{% for comment in article.comment_set.all %}
  <p>{{ comment.content }}</p>
{% endfor %}

<form action="{% url 'articles:comment_create' article.pk %}" method="POST">
  {% csrf_token %}
  {{ comment_form.as_p }}
  <input type="submit" value="댓글 작성">
</form>
```

## 핵심 요약
* **N:1 관계**는 여러 개의 자식 데이터가 하나의 부모 데이터를 참조하는 구조로, 외래키는 항상 "N(여러 개)"쪽 테이블에 위치한다.
* Django에서는 `ForeignKey`로 N:1 관계를 정의하며, `on_delete` 옵션(`CASCADE`, `PROTECT`, `SET_NULL`)으로 부모 삭제 시 자식의 처리 방식을 지정한다.
* 댓글처럼 URL 등 폼 외부의 값을 함께 저장해야 할 때는 `form.save(commit=False)`로 인스턴스만 먼저 만든 뒤, 필요한 값을 채워 넣고 `save()`를 호출하는 패턴을 사용한다.

# SW문제해결응용 백트래킹 정리

**완전 탐색**을 하되, 가능성이 없는 경로는 더 이상 진행하지 않고 되돌아가는 **백트래킹(Backtracking)** 기법과, 이를 활용한 문제 풀이를 정리한 문서입니다.

---

## 1. 백트래킹(Backtracking)이란?

* 해를 찾는 도중에 **막히면(=답이 될 가능성이 없으면) 되돌아가서** 다시 해를 찾아가는 기법
* 최적화(Optimization) 문제와 결정(Decision) 문제를 해결할 수 있음
  * **결정 문제:** 문제의 조건을 만족하는 해가 존재하는지 여부를 참(True)/거짓(False)으로 답하는 문제
* 어떤 노드(상태)의 유망성을 점검한 후, 유망하지 않다고 판단되면 그 노드의 부모로 되돌아가 다른 자손 노드를 검색

### 완전 탐색과의 차이 — 가지치기(Pruning)

* **완전 탐색(Brute-force):** 가능한 모든 경우를 다 검사 → 경우의 수가 많아지면 시간복잡도가 폭발적으로 증가
* **백트래킹:** 해가 될 수 없는 상태를 **유망하지 않다(promising하지 않다)** 고 판단하는 순간, 그 아래의 모든 경우를 탐색하지 않고 가지를 쳐냄(Pruning) → 실제 탐색하는 노드 수가 크게 줄어듦

### 백트래킹 알고리즘의 절차

1. 상태 공간을 트리(State Space Tree)로 구성
2. 루트에서 시작해 자식 노드로 이동하며 해를 확장
3. 각 노드에서 **유망성(Promising) 검사** 수행
   * 유망하면 → 자식 노드로 계속 진행
   * 유망하지 않으면 → 해당 노드의 자식들은 탐색하지 않고, 부모 노드로 돌아감(백트랙)
4. 모든 후보를 확인할 때까지 2~3을 반복

```python
def backtrack(state):
    if is_solution(state):
        process(state)          # 해를 찾았을 때 처리
        return

    for candidate in candidates(state):
        if is_promising(state, candidate):   # 유망성 검사 (가지치기)
            state.append(candidate)
            backtrack(state)                  # 다음 단계로 재귀 진입
            state.pop()                        # 되돌아오기(백트랙)
```

## 2. 문제풀이 — 부분집합의 합

* 집합 `S = {1, 2, 3, ..., N}`의 부분집합 중 원소의 합이 특정 값 `K`가 되는 부분집합을 찾는 문제
* 완전 탐색으로 풀면 부분집합의 개수가 `2^N`개이지만, 백트래킹으로 풀면 **합이 이미 K를 넘어선 상태**는 더 이상 원소를 추가하지 않고 가지치기할 수 있음

```python
N, K = 10, 15
answer_count = 0

def promising(sum_so_far):
    return sum_so_far <= K

def dfs(idx, sum_so_far):
    global answer_count
    if not promising(sum_so_far):    # 유망하지 않으면 즉시 가지치기
        return
    if idx == N + 1:
        if sum_so_far == K:
            answer_count += 1
        return
    dfs(idx + 1, sum_so_far + idx)   # idx를 부분집합에 포함
    dfs(idx + 1, sum_so_far)          # idx를 부분집합에서 제외

dfs(1, 0)
print(answer_count)
```

* 합이 `K`를 초과하는 순간 더 이상 원소를 더할 필요가 없으므로 해당 분기 전체를 탐색하지 않음 → 완전 탐색보다 훨씬 빠르게 종료

## 3. 문제풀이 — 1865. 동철이의 일 분배

* N명의 직원에게 N개의 일을 분배하되, **한 사람이 정확히 하나의 일만 맡을 수 있는** 경우의 수를 구하는 문제 (순열 기반 완전 탐색 + 가지치기)
* 각 직원이 할 수 있는 일의 목록이 주어질 때, 이미 배정된 일은 다시 배정할 수 없으므로 **방문 배열(visited)** 로 유망성을 검사하며 백트래킹으로 탐색

```python
def dfs(employee, visited, assign_count):
    global total_ways
    if employee == N:
        total_ways += 1
        return
    for job in able_jobs[employee]:      # 해당 직원이 할 수 있는 일들
        if not visited[job]:             # 아직 배정되지 않은 일이면 (유망성 검사)
            visited[job] = True
            dfs(employee + 1, visited, assign_count + 1)
            visited[job] = False          # 백트랙: 배정 취소 후 다음 후보 시도
```

* 이미 배정된 일에 대해서는 더 이상 그 분기를 탐색하지 않으므로, 순열을 모두 나열(`N!`)하는 것보다 훨씬 적은 경우만 탐색하게 됨

## 핵심 요약
* **백트래킹**은 상태 공간 트리를 탐색하다가 해가 될 가능성이 없는(유망하지 않은) 노드를 만나면 그 아래 경우를 더 탐색하지 않고 즉시 되돌아가는 **가지치기 기반 완전 탐색**이다.
* 일반 완전 탐색이 모든 경우(`O(2^N)`, `O(N!)` 등)를 다 확인하는 것과 달리, 백트래킹은 **유망성 검사(promising check)** 를 통해 불필요한 탐색을 줄여 실질적인 성능을 크게 개선한다.
* **부분집합의 합**은 합이 목표값을 넘는 순간 가지치기하고, **동철이의 일 분배**는 이미 배정된 일을 방문 배열로 걸러내며 재귀적으로 백트래킹을 수행한다.

## 1. 4013. 특이한 자석

### 문제 상황

* 4개의 톱니 모양 자석이 일렬로 맞물려 있고, 각 자석은 8개의 영역으로 나뉘어 N극(0)과 S극(1)을 가짐
* 자석을 돌리면, **서로 맞닿은 면의 극이 다르면(N-S) 인접한 자석도 반대 방향으로 같이 회전**하고, **극이 같으면(N-N, S-S) 회전하지 않음**
* K번 자석을 회전시키는 명령이 여러 번 주어질 때, 모든 명령 수행 후 4개 자석의 **위쪽 영역의 값(0 또는 1)** 으로 만들어지는 4자리 이진수를 10진수 점수로 환산해 총합을 구하는 문제

### 풀이 접근 — 시뮬레이션

1. 회전시키려는 자석을 기준으로, **왼쪽 자석들**을 순서대로 확인하며 맞닿는 면의 극이 다르면 함께 회전(다르면 반대로, 같으면 그 이후는 전파 중단)
2. 같은 방식으로 **오른쪽 자석들**도 확인하며 전파
3. 전파가 결정되면 각 자석을 실제로 회전(deque의 `rotate` 활용)

```python
from collections import deque

magnets = [deque(m) for m in magnet_list]   # 각 자석을 8칸짜리 deque로 표현
rotate_dir = [0, 0, 0, 0]                    # 각 자석의 회전 방향(1: 시계, -1: 반시계, 0: 정지)

def check_and_rotate(idx, direction):
    rotate_dir[idx] = direction
    # 왼쪽으로 전파 (idx-1, idx-2, ...)
    for i in range(idx, 0, -1):
        left, cur = magnets[i - 1], magnets[i]
        if left[2] != cur[6]:   # 맞닿은 면(오른쪽 자석의 6시 방향-왼쪽 자석의 2시 방향)의 극이 다르면
            rotate_dir[i - 1] = -rotate_dir[i]
        else:
            break
    # 오른쪽으로 전파도 동일한 방식으로 처리
    ...

    for i, d in enumerate(rotate_dir):
        if d == 1:
            magnets[i].rotate(1)     # 시계 방향 회전
        elif d == -1:
            magnets[i].rotate(-1)    # 반시계 방향 회전
```

* **핵심 포인트:** 회전이 실제로 일어나기 *전에* 모든 자석의 회전 여부를 먼저 결정한 뒤, 마지막에 한꺼번에 회전시켜야 함 (먼저 회전시키면 이후 판단 기준이 바뀌어버림)
* 원형 구조(8개 영역이 순환)를 다룰 때는 `deque.rotate()`를 사용하면 간단하게 구현 가능

## 2. 5215. 햄버거 다이어트

### 문제 상황

* N가지 재료가 있고, 각 재료는 **맛(score)** 과 **칼로리(cal)** 값을 가짐
* 주어진 **칼로리 제한(L)** 을 넘지 않는 선에서, 재료를 골라 만든 햄버거의 **맛의 합이 최대**가 되도록 하는 문제
* 재료를 쪼갤 수 없으므로(포함 or 미포함), 전형적인 **0-1 Knapsack** 유형의 문제 → 완전 탐색(부분집합) + 가지치기(백트래킹)으로 해결

### 풀이 접근 — 백트래킹 기반 부분집합 탐색

```python
N, L = 5, 15
ingredients = [(score1, cal1), (score2, cal2), ...]
max_score = 0

def dfs(idx, total_score, total_cal):
    global max_score
    if total_cal > L:            # 유망성 검사: 칼로리를 이미 초과했다면 가지치기
        return
    if idx == N:
        max_score = max(max_score, total_score)
        return

    score, cal = ingredients[idx]
    dfs(idx + 1, total_score + score, total_cal + cal)  # 재료 포함
    dfs(idx + 1, total_score, total_cal)                  # 재료 미포함

dfs(0, 0, 0)
print(max_score)
```

* **부분집합의 합** 문제와 구조가 동일: 원소를 "포함/미포함" 두 갈래로 나누어 재귀 탐색
* 칼로리 총합이 제한 `L`을 넘어서는 순간 더 이상 진행할 필요가 없으므로 **즉시 반환(가지치기)** → 완전 탐색(`2^N`)보다 실제 탐색량이 크게 줄어듦

---

## 핵심 요약
* **특이한 자석**은 자석 간 극성에 따른 회전 전파를 정확히 시뮬레이션하는 문제로, 회전 여부를 모두 결정한 뒤 한 번에 반영해야 하며 `deque.rotate()`로 원형 회전을 간단히 구현할 수 있다.
* **햄버거 다이어트**는 재료의 포함/미포함을 나누어 탐색하는 0-1 Knapsack 유형 문제로, 칼로리 제한을 넘는 순간 가지치기하는 백트래킹으로 효율적으로 해결한다.
* 두 문제 모두 "완전 탐색 골격 + 상황에 맞는 유망성 검사(가지치기)"라는 백트래킹의 기본 패턴을 그대로 적용해 풀 수 있다.

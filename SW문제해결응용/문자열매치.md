# SW문제해결응용 문자열매치 정리

긴 텍스트 안에서 특정 패턴 문자열의 위치를 찾는 **문자열 매칭(String Matching)** 문제의 다양한 접근법을, 단순한 **브루트포스**부터 시작해 **라빈-카프**, **보이어-무어**, **KMP**까지 정리한 문서입니다.

---

## 1. 문자열 매치란?

* 텍스트 `T`(길이 `n`) 안에서 패턴 `P`(길이 `m`)가 나타나는 위치를 모두 찾는 문제
* 가장 단순한 방법은 텍스트의 모든 시작 위치에서 패턴이 일치하는지 하나하나 비교하는 것이지만, 텍스트/패턴이 길어질수록 비효율적 → 이를 개선하는 다양한 알고리즘이 존재

---

## 2. 브루트포스(Brute-force) 패턴 매칭

* 텍스트의 각 위치 `i`(0 ~ n-m)에서, 패턴과 문자를 처음부터 끝까지 하나씩 비교
* 불일치가 발생하면 텍스트 위치를 **한 칸만** 옮겨서 처음부터 다시 비교

```python
def brute_force(text, pattern):
    n, m = len(text), len(pattern)
    result = []
    for i in range(n - m + 1):
        j = 0
        while j < m and text[i + j] == pattern[j]:
            j += 1
        if j == m:
            result.append(i)   # i번 위치에서 패턴과 일치
    return result
```

* 시간복잡도: 최악의 경우 `O(n*m)` — 구현은 간단하지만 텍스트/패턴이 반복적인 구조일수록 비효율적인 비교가 많이 발생

---

## 3. 라빈-카프(Rabin-Karp) 알고리즘

* 문자열을 직접 비교하는 대신, 문자열을 숫자(**해시값**)로 변환해서 **해시값이 같은 경우에만** 실제 문자열을 비교
* 텍스트를 한 칸씩 옮길 때마다 해시값을 처음부터 다시 계산하지 않고, 이전 해시값에서 **앞 문자를 빼고 뒷 문자를 더하는 방식(슬라이딩 윈도우)** 으로 `O(1)`에 갱신

```python
def rabin_karp(text, pattern):
    n, m = len(text), len(pattern)
    base, mod = 256, 1_000_000_007

    pattern_hash = 0
    text_hash = 0
    h = pow(base, m - 1, mod)   # 맨 앞자리를 뺄 때 필요한 base^(m-1)

    for i in range(m):
        pattern_hash = (pattern_hash * base + ord(pattern[i])) % mod
        text_hash = (text_hash * base + ord(text[i])) % mod

    result = []
    for i in range(n - m + 1):
        if pattern_hash == text_hash:        # 해시가 같을 때만 실제 비교(해시 충돌 가능성 대비)
            if text[i:i + m] == pattern:
                result.append(i)
        if i < n - m:
            text_hash = ((text_hash - ord(text[i]) * h) * base + ord(text[i + m])) % mod
    return result
```

* 대부분의 경우 해시 비교(`O(1)`)만으로 불일치를 빠르게 걸러내므로 평균 `O(n+m)`에 가까운 성능
* **여러 개의 패턴을 동시에 찾을 때(중복 문서 검사, 표절 검사 등)** 특히 유용

## 4. 보이어-무어(Boyer-Moore) 알고리즘

* 대부분의 문자열 편집기·grep 등에서 사용되는 실전에서 빠른 알고리즘
* 패턴을 **뒤에서부터 앞으로** 비교하며, 불일치가 발생하면 **불일치 문자(Bad Character)** 정보를 이용해 패턴을 여러 칸 한번에 건너뜀
* 텍스트의 불일치 문자가 패턴 내에 존재하면 그 위치에 맞춰 패턴을 이동시키고, 존재하지 않으면 패턴 전체를 건너뜀

```python
def boyer_moore_bad_char(text, pattern):
    n, m = len(text), len(pattern)
    last = {ch: idx for idx, ch in enumerate(pattern)}   # 패턴 내 각 문자의 마지막 등장 위치

    result = []
    i = 0
    while i <= n - m:
        j = m - 1
        while j >= 0 and pattern[j] == text[i + j]:
            j -= 1
        if j < 0:
            result.append(i)
            i += 1
        else:
            bad_char_idx = last.get(text[i + j], -1)
            i += max(1, j - bad_char_idx)   # 불일치 문자 정보를 이용해 여러 칸 이동
    return result
```

* 평균적으로 텍스트의 모든 문자를 다 비교하지 않아도 되어, 실전에서는 `O(n/m)`에 가까운 성능을 보이는 경우가 많음

## 5. KMP(Knuth-Morris-Pratt) 알고리즘

* 브루트포스처럼 불일치 시 무조건 한 칸만 옮기지 않고, **이미 비교했던 정보(패턴 자체의 반복 구조)** 를 활용해 필요한 만큼만 건너뛰는 알고리즘
* 핵심 아이디어: 패턴에서 **접두사(prefix)이면서 동시에 접미사(suffix)인 부분 문자열의 최대 길이**를 미리 계산한 **실패 함수(Failure Function, `pi` 배열)** 를 이용

### 실패 함수(pi 배열) 만들기

```python
def get_pi(pattern):
    m = len(pattern)
    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]        # 접두사 위치를 이전 실패 정보 이용해 이동
        if pattern[i] == pattern[j]:
            j += 1
            pi[i] = j
    return pi
```

### KMP 탐색

```python
def kmp(text, pattern):
    n, m = len(text), len(pattern)
    pi = get_pi(pattern)
    result = []
    j = 0
    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = pi[j - 1]        # 불일치 시, 실패 함수를 이용해 되돌아갈 위치를 O(1)에 결정
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            result.append(i - m + 1)  # 매칭 성공
            j = pi[j - 1]
    return result
```

* 텍스트 포인터 `i`는 **뒤로 돌아가지 않고** 항상 앞으로만 진행하므로 시간복잡도 `O(n + m)` 보장

---

## 6. 알고리즘 비교

| 알고리즘 | 핵심 아이디어 | 평균 시간복잡도 | 특징 |
| --- | --- | --- | --- |
| 브루트포스 | 모든 위치에서 처음부터 끝까지 직접 비교 | `O(n*m)` | 구현이 가장 단순 |
| 라빈-카프 | 문자열을 해시값으로 변환 후 비교 | `O(n+m)` (평균) | 여러 패턴 동시 검색에 유리 |
| 보이어-무어 | 뒤에서부터 비교, 불일치 문자로 여러 칸 점프 | `O(n/m)` (실전 평균) | 실무 텍스트 편집기 등에서 널리 사용 |
| KMP | 패턴 자체의 접두사/접미사 구조(실패 함수) 활용 | `O(n+m)` (최악 보장) | 텍스트 포인터가 절대 후퇴하지 않음 |

---

## 핵심 요약
* 문자열 매칭은 텍스트에서 패턴이 등장하는 위치를 찾는 문제이며, 가장 단순한 **브루트포스**는 불일치 시 한 칸만 이동해 `O(n*m)`이 걸린다.
* **라빈-카프**는 문자열을 해시값으로 변환해 비교 비용을 줄이고, **보이어-무어**는 패턴을 뒤에서부터 비교하며 불일치 문자 정보로 여러 칸을 한 번에 건너뛴다.
* **KMP**는 패턴 자체의 접두사=접미사 구조를 담은 실패 함수(`pi` 배열)를 이용해, 불일치가 나도 텍스트 포인터는 후퇴하지 않고 `O(n+m)`을 보장한다.
* 상황(패턴 개수, 텍스트 특성, 구현 난이도)에 따라 적절한 문자열 매칭 알고리즘을 선택하는 것이 중요하다.

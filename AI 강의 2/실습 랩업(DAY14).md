# AI 강의 Ⅱ 실습 랩업(DAY14) 정리

AI강의Ⅱ 전 과정에서 다룬 핵심 주제들을 코드로 직접 실행해보며 복습하는 **Wrap Up** 세션입니다. Python/수학 기초부터 CNN·RNN·Transformer, RAG·PEFT, 그리고 API 실습과 관통 PJT 활용 아이디어까지 챕터별로 정리합니다.

---

## 1. AI를 위한 Python과 Math / EDA

* AI·딥러닝 모델을 이해하기 위한 최소한의 **선형대수(벡터/행렬 연산)** 와 **통계** 기초를 복습
* **EDA(탐색적 데이터 분석):** 모델링 이전에 데이터의 분포, 결측치, 이상치를 먼저 파악하는 단계 — "좋은 모델은 좋은 데이터 이해에서 시작된다"는 원칙을 다시 확인

---

## 2. MLP (Multi-Layer Perceptron)

* 입력층-은닉층-출력층으로 구성된 가장 기본적인 신경망 구조로, 각 층 사이의 **가중치(Weight)** 와 **활성화 함수(Activation Function)** 를 통해 비선형적인 패턴을 학습
* 학습 과정은 **순전파(Forward Propagation)** 로 예측값을 계산하고, **역전파(Backpropagation)** 로 오차를 각 가중치에 전달해 경사하강법으로 가중치를 갱신하는 방식

---

## 3. 토큰화 / 임베딩

* **토큰화(Tokenization):** 텍스트를 모델이 처리할 수 있는 최소 단위(토큰)로 분리하는 과정
* **임베딩(Embedding):** 토큰(이산적인 값)을 모델이 의미 관계를 학습할 수 있는 **연속적인 벡터 공간**으로 변환하는 과정 — 의미가 비슷한 단어일수록 벡터 공간에서 가까운 위치에 놓이게 됨

---

## 4. 합성데이터와 데이터 증강

* **합성 데이터(Synthetic Data):** 실제 수집이 어렵거나 부족한 데이터를 인공적으로 생성해 보완
* **데이터 증강(Data Augmentation):** 기존 데이터에 회전/자르기/노이즈 추가 등의 변형을 가해 데이터 양을 늘리고, 모델이 다양한 상황에도 강건(robust)하게 학습되도록 하는 기법

---

## 5. CNN (Convolutional Neural Network)

* 이미지·영상에서 시각적 특징을 기반으로 사물을 인식하는 딥러닝 알고리즘
* 2012년 CNN 기반의 **AlexNet**이 등장하며 이른바 "AI 겨울"을 끝내고 현재의 딥러닝 붐을 여는 계기가 됨

```
Input → Convolutional Layer → Pooling Layer → (반복) → Flatten → Fully Connected Layer → 출력
```

* **Convolutional Layer:** 필터(커널)로 이미지의 지역적 특징(경계, 패턴 등)을 추출
* **Pooling Layer:** 특징 맵의 크기를 줄여 연산량을 줄이고 주요 특징만 남김
* **Flatten + Fully Connected Layer:** 추출된 특징을 1차원으로 펼쳐 최종 분류/예측 수행

---

## 6. RNN (Recurrent Neural Network)

* 순서가 있는 데이터(텍스트, 시계열 등)를 다루기 위해, 이전 시점의 출력을 다음 시점의 입력으로 함께 사용하는 순환 구조를 가진 신경망
* 시퀀스가 길어질수록 앞쪽 정보가 뒤로 잘 전달되지 못하는 **장기 의존성(Long-term Dependency)** 문제가 있어, 이를 개선한 LSTM/GRU 등이 등장

---

## 7. Attention과 Transformer 모델 / Transformer 기반 이미지 모델

* **Attention:** 시퀀스의 모든 위치를 동시에 참고하면서, 현재 처리 중인 토큰과 **관련이 높은 부분에 더 큰 가중치**를 부여하는 메커니즘 — RNN의 순차 처리 한계를 극복
* **Transformer:** Attention을 핵심 구조로 사용해 병렬 처리가 가능하며, 오늘날 대부분의 대규모 언어 모델(LLM)의 기반이 되는 아키텍처
* **Transformer 기반 이미지 모델(ViT 등):** 이미지를 일정 크기의 패치(patch)로 나누어 각 패치를 하나의 "토큰"처럼 취급, Transformer 구조를 이미지 인식에도 적용

---

## 8. RAG / PEFT

* **RAG(Retrieval-Augmented Generation):** 생성형 AI가 답변하기 전, 외부 문서/DB에서 관련 정보를 **검색(Retrieval)** 해 프롬프트에 함께 제공함으로써 최신 정보나 근거 있는 답변을 생성하도록 하는 기법
* **PEFT(Parameter-Efficient Fine-Tuning):** 거대 언어 모델 전체를 재학습하는 대신, **일부 파라미터만 추가/조정**해 적은 자원으로도 특정 작업에 맞게 모델을 미세조정하는 방법론

---

## 9. API 실습 (Post 요청)

* 학습한 모델(혹은 외부 AI 서비스)을 실제 애플리케이션에서 사용하려면, HTTP `POST` 요청으로 입력 데이터를 보내고 결과를 응답받는 API 호출 실습을 진행
* 노트북 환경(Colab 등)에서 직접 요청을 보내보며, 실제 서비스에 AI 모델을 연동할 때의 기본적인 흐름(요청 구성 → 호출 → 응답 파싱)을 복습

---

## 10. 관통 PJT 활용 아이디어 — Image to Text + Voice to Text

* 영화의 한 장면 이미지와 음성을 각각 Text로 변환해 다음 장면을 예측/생성하는 서비스 아이디어
* AI강의Ⅱ에서 배운 **이미지 인식(CNN/ViT), 텍스트 생성(Transformer), 데이터 파이프라인** 지식을 조합하면, 관통 프로젝트에서도 이미지·음성 등 멀티모달 데이터를 다루는 기능을 기획해볼 수 있음을 시사

---

## 핵심 요약
* AI강의Ⅱ는 Python/수학·EDA 같은 기초부터, MLP → CNN/RNN(이미지·시퀀스 처리) → Attention/Transformer(현대 LLM의 기반) → RAG/PEFT(실전 활용·경량화)까지 이어지는 하나의 큰 흐름으로 구성되어 있다.
* 토큰화·임베딩은 텍스트를 모델이 이해할 수 있는 벡터로 바꾸는 과정이며, 데이터 증강은 부족한 데이터를 보완해 모델을 더 강건하게 만든다.
* 마지막 실습(API 연동, 이미지+음성 기반 서비스 아이디어)은 지금까지 배운 개념들을 실제 서비스(관통 PJT 등)에 어떻게 응용할 수 있는지 연결해보는 단계이다.

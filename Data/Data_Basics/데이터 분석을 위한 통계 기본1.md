# 데이터 분석을 위한 기초 통계 1 정리

데이터를 요약하는 **기초 통계량**, 사건들 사이의 관계를 다루는 **조건부 확률/베이즈 정리**, 그리고 데이터를 얻는 과정에서 발생하는 **표본 편향과 분포**에 대해 정리합니다.

---

## 1. 기초 통계량

데이터를 처음 살펴볼 때는 데이터의 **크기, 분포, 중심, 퍼짐**을 파악하는 것이 첫 단계입니다. 수많은 값을 일일이 보는 것은 불가능에 가까우므로, 대표값(위치)과 변동성(퍼짐)을 요약하는 통계량을 활용합니다.

### 위치를 추정하는 방법
| 통계량 | 설명 |
| --- | --- |
| 평균 (mean) | 전체 값을 더해 개수로 나눈 값. 전체적인 중심을 나타내지만 이상치에 민감 |
| 절사평균 (trimmed mean) | 상·하위 극단값 일부를 제거하고 계산한 평균으로 이상치 영향을 줄임 |
| 가중평균 (weighted mean) | 각 값의 중요도(가중치)를 반영해 계산한 평균 |
| 중간값 (median) | 정렬된 데이터의 중앙 위치 값. 이상치에 영향을 안 받아 안정적 |
| 가중 중간값 (weighted median) | 값의 가중치를 고려해 중앙 위치를 결정 |
| 백분위수 (percentile) | 데이터 100등분했을 때 특정 위치의 값으로 분포의 형태와 위치를 파악 |

### 변이(퍼짐)를 추정하는 방법
* **분산(Variance):** 평균으로부터 얼마나 퍼져 있는지 나타내는 지표
* **표준편차(Standard deviation):** 데이터의 편차(각 값에서 평균을 뺀 값)의 제곱근
* **사분할 범위(IQR):** 25번째 백분위수와 75번째 백분위수의 차이

### 활용
* **이상치 탐색:** 데이터를 분석할 때 극단적으로 크거나 작은 값(이상치)을 찾는 것이 중요 (예: 평균 몸무게가 60kg인데 120kg이 섞여 있다면 이상치 가능성)
* **비교와 예측:** 두 그룹을 비교할 때 평균/중앙값/표준편차를 이용해 차이·특성을 비교
* **적절한 통계량 선택:** 데이터가 대칭형으로 분포되어 있다면 평균을, 왜곡된 분포라면 중앙값이 더 적절 (예: 연봉·집값처럼 오른쪽 꼬리가 긴 분포는 중앙값 사용 권장)

## 2. 조건부 확률과 베이즈 정리

### 조건부 확률
어떤 정보(B)가 주어졌을 때, 그 조건 아래에서 다른 사건(A)이 일어날 확률을 의미합니다.

```
P(A | B) = P(A ∩ B) / P(B)
```

* 예) "맑은 날 비가 오지 않을 확률" = P(비가 안옴 ∩ 맑은 날) / P(맑은 날)

### 베이즈 정리
직접 구하기 어려운 `P(A|B)`를, 더 구하기 쉬운 `P(B|A)`, `P(A)`, `P(B)`로 계산할 수 있게 해주는 공식입니다. 즉, 베이즈 정리는 조건부 확률의 방향을 뒤집어 주는 역할을 하며 데이터 분석·머신러닝에서 자주 쓰이는 개념입니다.

```
P(A | B) = P(B|A) P(A) / P(B)
```

* 현실에서는 실제로 측정 가능한 확률: `A → B`, 우리가 알고 싶은 확률: `B → A` 인 경우가 많음
* **예: 추천 시스템** - 사용자의 행동으로부터 취향을 추론
  * A: 사용자가 어떤 영화를 클릭했다
  * B: 사용자가 실제로 좋아하는 장르 → P(행동 | 취향)은 모델링하기 쉬움, 하지만 알고 싶은 건 P(취향 | 행동)

### 나이브 베이즈 분류 (스팸 메일 판단 예시)
* 스팸 메일에서 특정 단어가 등장하는 비율을 관찰
* 관찰 가능한 확률(사전 확률)을 이용해 알고 싶은 확률(사후 확률)을 계산
```python
# 관찰 가능한 확률들
P_word_given_spam = 0.7    # 스팸 메일 중 특정 단어가 등장할 확률
P_word_given_normal = 0.1  # 정상 메일 중 단어 등장 확률
P_spam = 0.4               # 전체 메일 중 스팸 비율
P_normal = 0.6             # 전체 메일 중 정상 비율

# 전체 단어 등장 확률
P_word = P_word_given_spam * P_spam + P_word_given_normal * P_normal

# 우리가 알고 싶은 확률: 단어가 등장했을 때 스팸일 확률
P_spam_given_word = (P_word_given_spam * P_spam) / P_word
print("P(스팸 | 단어) =", round(P_spam_given_word, 3))
```

## 3. 표본 추출과 편향

### 모집단과 표본
* **모집단:** 연구 대상이 되는 전체 집단
* **표본:** 모집단에서 일부를 선택한 것
* 모든 사람(모집단)을 조사할 수 없으므로, 일부를 뽑아서(표본) 조사한 후 이를 바탕으로 모집단의 특성을 추정합니다.

### 표본 조사의 필요성
* **인구조사(Census):** 전체 국민을 조사하는 방법 → 가장 정확하지만 시간과 비용이 많이 소요
* **표본조사(Survey):** 모든 사람을 조사하는 것이 어렵기 때문에 일부만 신중히 선택 → 정확한 결과를 위해 표본을 신중히 선택해야 함
* 주의점: 표본이 특정 지역이나 연령대에 편중된다면, 전체 모집단의 의견을 제대로 반영하지 못하는 **표본 편향**이 발생

### 표본 추출 방법
| 방법 | 설명 | 예시 |
| --- | --- | --- |
| 단순 무작위 추출 | 모든 사람이 동일한 확률로 뽑힘 | 모자 속에서 랜덤하게 종이 한 장 뽑기 |
| 층화추출 | 모집단을 그룹(층)으로 나눈 후, 각 층에서 대표 인원 뽑기 | 학년별 대표 한 명씩 뽑기 |
| 계통추출 | 모집단을 일정 간격으로 나누어, 표본을 추출 | 첫 번째 학생을 랜덤 선택 후, 5명마다 한 명씩 |
| 군집추출 | 모집단을 여러 그룹(군집)으로 나눈 후, 몇 개의 군집 전체를 선택 | 한 반을 통째로 뽑아 조사 |
| 편의추출 | 쉽게 접근할 수 있는 표본을 선택 (비추천) | 가까이 있는 사람들만 설문조사 → 편향된 표본은 잘못된 결론을 내릴 수 있음 |

**임의 추출(무작위 추출)** 은 모집단에서 특정한 규칙 없이 무작위로 표본을 선택하는 방법으로, 복원추출과 비복원추출이 있습니다.

임의 추출이 필요한 이유:
1. **공정성 유지:** 모든 대상이 동일한 확률로 선택될 기회 제공
2. **대표성 확보:** 특정 그룹에 치우치지 않고 모집단 전체를 반영
3. **편향 방지:** 의도적인 선택(예: 특정 지역, 특정 연령대만 선택)을 막아 객관적인 데이터 확보
4. **통계 분석의 신뢰도 증가:** 모집단을 잘 반영한 표본이면, 정확한 결론을 도출할 가능성이 높아짐

> 표본 크기가 클수록 표본 평균의 변동성(표준오차)이 줄어들며, 모집단 평균과 더욱 가까워집니다 (표본 평균의 분포는 정규분포에 가까워짐 — 중심극한정리와 연결되는 개념).

### 표본 편향(Sampling Bias)의 개념과 사례
* **표본 편향:** 모집단을 대표하지 못하는 잘못된 표본을 선택하여 조사 결과가 왜곡된 현상. 핵심 원인은 임의 표본 추출을 지키지 못한 것.
* **사례 - 리터러리 다이제스트:** 1936년 미 대선 여론조사에서 240만 명 대상 조사 → 루스벨트 패배 예상, 그러나 실제 선거에서는 루스벨트가 압도적 승리. 표본이 부유한 사람들(잡지·전화·자동차 등록자) 위주로 편중되어 모집단(전체 유권자)을 대표하지 못했음.

### 표본 편향을 줄이는 방법
1. **무작위 추출 강화:** 모든 개체가 동일한 확률로 선택되도록 공정성을 높임 (예: 대통령 지지율 조사 시 전국 유권자를 무작위로 선정)
2. **층화 추출 활용:** 성별·연령·지역·직업 등에 따라 그룹을 나눈 후, 각 그룹에서 무작위로 표본을 추출해 다양한 특성을 고르게 반영 (선거 여론조사의 성별·연령대·지역별 비례 배정 등)
3. **계통 추출 적용:** 일정한 간격으로 표본을 추출 (예: 생산라인에서 1,000개 중 매 100번째 제품 무작위 검사) — 빠르고 쉽지만 모집단에 주기적 패턴이 있으면 편향 발생 가능
4. **표본 크기 확대:** 표본 크기를 늘려 모집단을 더 정확히 반영 (표본이 클수록 비용·시간이 더 소요되는 트레이드오프 존재)
5. **가중치 적용:** 특정 그룹이 과소/과대 대표된 경우, 결과에 보정 가중치를 곱해 왜곡을 줄임 (국민건강영양조사 등에서 활용)

### 표본조사의 오류 두 가지
| 구분 | 설명 |
| --- | --- |
| 표본오차 (Sampling Error) | 표본을 뽑는 과정에서 우연히 생기는 차이. 같은 방법으로 뽑아도 표본마다 값이 조금씩 다름. 표본 크기를 키우면 줄일 수 있음 |
| 비표본오차 (Non-Sampling Error) | 조사 절차/설계 자체의 문제로 생기는 체계적 오류(=편향). 응답하지 않음, 응답 왜곡, 특정 집단만 표본화 등. 표본 크기를 아무리 키워도 해결되지 않음 |

### 선택 편향(Selection Bias) vs 표본 편향(Sampling Bias)
| 구분 | 표본 편향 (Sampling Bias) | 선택 편향 (Selection Bias) |
| --- | --- | --- |
| 정의 | 모집단을 대표하지 않는 표본을 선택하는 문제 (표본 틀 자체가 대표성이 없음) | 표본을 뽑는 과정 자체가 특정한 사람들만 선택되도록 설계되어 결과가 왜곡되는 문제 (표본이 모이는 과정이 왜곡) |
| 원인 | 지역·연령·성별 등 특정 그룹 과대/과소 표집 | 자발적 참여, 특정 시간대 조사, 참여 조건 등으로 특정 그룹만 들어옴 |
| 예시 | 20대만 대상으로 여론조사 | 건강 관심자만 건강검진 연구에 참여(자발적 참여) |

**선택 편향이 발생하는 이유:**
* 특정 그룹만 포함되는 경우 (연구 설계 과정에서 특정 특성을 가진 사람들만 표본으로 포함)
* 자발적 참여 (연구에 참여하는 사람이 스스로 결정하면, 연구에 적극적으로 참여하는 사람만 편향되게 포함될 가능성이 높음) — 예: 건강검진 연구에서 건강에 관심 있는 사람만 참여하면 편향 발생

**사례**
* 신약 임상 시험에 자발적으로 참여한 사람들만 시험했다면 → 실제로 약이 필요 없는(건강한) 사람들 위주로 편향돼, 약의 효과가 다르게 나타날 수 있음
* 병원 방문자를 대상으로 한 연구 → 병원에 오는 환자만으로 질병 위험 요인을 분석하면, 병원을 방문하지 않은(모집단에 없는) 사람들의 결과가 편향될 수 있음

### 타이타닉 데이터로 보는 선택 편향 예제
* "타이타닉 생존 경험을 확인하기 위해 인터뷰 조사"를 진행했다고 가정
* 인터뷰는 생존자에게만 가능 → 생존자 중심으로만 데이터가 수집되어, 1등석 승객이 인터뷰 데이터에서도 1등석 답변 비율이 매우 높게 나타남
* 실제로는 클래스별 탑승객 수 대비 생존자 비율(전체 생존율 0.38, 1등석 0.63, 2등석 0.47, 3등석 0.24)과 인터뷰(생존자) 중심 데이터의 클래스 비율은 서로 다르게 나타남 → **선택 편향 발생**

## 4. 분포에 대한 이해

* **분포(Distribution):** 데이터가 어떤 값 주변에 어떻게 퍼져 있는지(흩어져 있는지)를 나타내는 것
* 예) 키 조사 - 모든 친구의 키가 170cm라면 데이터가 한 곳에 집중되어 있음(변이가 적음). 친구들의 키가 150~190cm로 다양하다면 데이터가 넓게 퍼져 있음(변이가 큼)
* 즉, 분포를 보면 데이터가 어떻게 생겼는지(중심에 모여 있는지, 넓게 퍼져 있는지)를 알 수 있습니다.

### 분포의 필요성
* **데이터의 패턴 파악:** 데이터가 대체로 어디에 몰려 있는지(중심 경향) 확인
* **이상치 발견:** 극단적으로 크거나 작은 값(이상치)을 찾는 것이 중요
* **비교와 예측 가능:** 두 개 이상의 그룹을 비교할 때 어떤 차이가 있는지 시각적으로 확인 가능 (예: 남학생과 여학생의 키 분포 비교)
* **적절한 분석 방법 선택:** 데이터의 분포 형태에 따라 평균, 중앙값 등을 선택하여 분석 가능

### 분포 시각화 방법
| 방법 | 설명 |
| --- | --- |
| 히스토그램 (Histogram) | 데이터를 막대 그래프로 나타낸 것. 전체적인 분포를 쉽게 확인 가능 |
| 박스 플롯 (Box Plot) | 데이터의 최소값, 중앙값(50%), 1사분위(25%), 3사분위(75%)를 표현. 데이터의 퍼짐 정도(분산)와 이상치를 확인하는 데 유용 |
| 밀도 곡선 (Density Plot) | 데이터를 연속적인 곡선 형태로 나타내어 데이터의 분포를 부드럽게 표현. 히스토그램처럼 데이터를 나누지 않고 연속적인 곡선으로 표현, 데이터의 중심과 분포의 형태를 더 부드럽게 볼 수 있음 |

박스 플롯은 `min - lower quartile(Q1) - median - upper quartile(Q3) - max` 순서로 구성되며, Q1~Q3 사이의 구간을 사분위 범위(IQR, interquartile range)라고 부릅니다.

## 핵심 요약
* 데이터를 요약할 땐 **위치(평균/중앙값 등)** 와 **변이(분산/표준편차/IQR)** 를 함께 봐야 이상치와 분포 형태를 파악할 수 있습니다.
* **베이즈 정리**는 구하기 쉬운 조건부 확률(P(B|A))로부터 구하기 어려운 확률(P(A|B))을 계산하게 해주며, 나이브 베이즈 분류의 기반이 됩니다.
* 표본은 **무작위성**이 핵심이며, 층화·계통·군집추출 등으로 대표성을 높이고 표본 편향/선택 편향을 줄여야 신뢰할 수 있는 분석이 가능합니다.
* 분포는 히스토그램, 박스플롯, 밀도곡선으로 시각화하여 중심·퍼짐·이상치를 한눈에 파악할 수 있습니다.

## 1. 확률분포와 표본분포

### 확률분포(Probability Distribution)
* 데이터가 나타날 수 있는 모든 값과 그 값의 나올 확률을 정리한 것 (예: 사람의 키, 시험 점수, 동전 던지기 결과 등)
* 확률분포가 가지는 의의: 데이터가 어느 값 주변에 얼마나 모여 있는가? 특정 값이 나타날 가능성은 어느 정도인가?
* 크게 두 종류로 구분
  * **연속형 분포:** 정규분포, 균등분포 등
  * **이산형 분포:** 이항분포, 포아송분포 등
* 확률분포를 이해하면 데이터의 패턴과 특징을 설명할 수 있고 예측 모델과 통계적 추론에서 적합한 분석 방법을 선택할 수 있습니다.

### 대표적인 분포의 종류
| 분포 유형 | 설명 | 활용 예 |
| --- | --- | --- |
| 정규분포 | 평균을 중심으로 대칭적인 종 모양 분포 | 키, 몸무게, 시험 점수 |
| 균등분포 | 모든 값이 같은 확률을 가짐 | 난수 생성, 시뮬레이션 |
| 이항분포 | 성공/실패 같은 이진(두 가지) 결과 모델링 | 이메일 클릭률, 제품 불량률 예측 |
| 포아송 분포 | 일정한 시간/공간 내에서 사건 발생 횟수 모델링 | 콜센터 문의 수 |

### 정규분포 (Normal Distribution)
* 데이터가 평균을 중심으로 좌우 대칭인 종 모양을 띠는 분포
```
f(x) = 1/(σ√(2π)) · e^(-(x-μ)²/2σ²)
```
* μ = 평균(Mean), σ = 표준편차(Standard Deviation)
* **주요 특성**
  * 평균(μ)과 표준편차(σ)로 모양이 결정됨
  * 평균값이 가장 많고 양옆으로 갈수록 빈도가 적어짐
  * **대칭성:** 평균(μ) = 중앙값(median) = 최빈값(mode)
  * **68-95-99.7 법칙:** 데이터의 68%가 ±1 표준편차, 95%가 ±2 표준편차, 99.7%가 ±3 표준편차 내에 존재
* **활용 예시**
  * 인구통계학: 사람들의 키·체중 같은 데이터 분석 시 정규분포를 활용 (예: 한국 성인 남성 평균 키 약 172cm)
  * 머신러닝: 많은 알고리즘이 데이터의 분포를 정규분포로 가정. 회귀 문제에서는 각 클래스에 속할 확률을 계산해 가장 높은 확률을 예측 결과로 선택하는 등, 확률 분포를 통해 데이터의 복잡성과 불확실성을 효과적으로 관리

### QQ-plot
* 데이터의 실제 분포가 정규분포와 얼마나 가까운지 그래프상으로 확인하는 대표적인 방법
* 보는 방법: x축은 이론적인 정규분포, y축은 실제 데이터 분포를 의미. **점들이 직선 위에 가까이 있으면 정규분포에 가까운 것**
* 점들이 직선을 크게 벗어나면 정규분포가 아닐 가능성이 큼

### 중심극한정리 (Central Limit Theorem, CLT)
* **모집단의 분포가 어떤 모양이든 상관없이, 충분히 큰 표본을 여러 번 추출해 계산한 표본평균의 분포는 정규분포에 가까워진다는 원리**
* 특징
  * 모집단이 어떤 모양(정규분포가 아니어도)이라도 상관없음
  * 표본 크기 n이 커질수록 표본평균의 분포가 정규분포에 가까워짐
  * 다양한 모집단에서도 정규 분포를 활용한 분석이 가능
* 실전 중요성: 금융, 경제 데이터 분석을 하는 경우에는 모집단의 분포를 알 수 없음. 하지만 표본 평균을 통해 정규 분포를 가정할 수 있어 주식/경제 지표 분석, 리스크 평가 등에서 정규 분포를 가정하여 확률을 계산할 수 있음

### 그 외 분포들
* **균등분포(Uniform Distribution):** 특정 범위 내에서 모든 값이 같은 확률을 가짐 (예: 로또 번호 추첨 - 이산형 균등분포)
* **이항분포(Binomial Distribution):** 독립적인 실험을 반복해 성공/실패 같은 이진 결과가 나오는 실험에서, 성공 횟수의 분포를 나타냄
  ```
  P(X=k) = C(n,k) p^k (1-p)^(n-k)
  ```
  n=총 시행 횟수, k=성공 횟수, p=성공 확률. 평균 `E(X)=np`, 분산 `Var(X)=np(1-p)`
  * 예: 동전을 10번 던졌을 때 앞면이 나오는 횟수, 주사위를 10번 굴렸을 때 특정 숫자(6)가 나오는 횟수
* **포아송 분포(Poisson Distribution):** 일정한 시간 또는 공간에서 사건이 발생하는 횟수를 모델링. 사건 발생 확률이 매우 작고 시행 횟수가 많을 때 이항분포의 근사로도 사용됨 (예: 1시간 당 은행 방문자 수, 1,000명 중 극소수만 걸리는 특정 질병에 걸리는 사람 수)
  ```
  P(X=k) = λ^k e^(-λ) / k!
  ```
  λ = 단위 시간당 평균 발생 횟수. λ가 작으면 그래프가 왼쪽에 치우치고(비대칭), λ가 커지면 정규분포와 비슷해짐

### 스튜던트의 t-분포
* 정규분포는 모집단의 분산을 알 때 사용 가능하고, 표본평균의 분포도 CLT로 인해 정규에 가까워짐. 하지만 현실에서는 모집단의 표준편차(σ)를 모르는 경우가 대부분이라, σ 대신 **표본표준편차(s)** 를 사용하게 되면 분포의 꼬리가 두꺼워지는데, 이걸 반영한 분포가 바로 **t-분포**
* **꼬리가 더 두꺼움** → 정규분포보다 극단값이 나타날 가능성을 더 현실적으로 반영
* **자유도(degree of freedom):** 간단히 말해 데이터가 자유롭게 움직일 수 있는지를 나타내는 수. 자유도가 작을수록 꼬리가 두꺼워지고, 자유도가 커질수록 정규분포와 비슷해짐
* 표본 크기(n)가 작거나 모집단의 표준편차를 정확히 모를 때 자주 사용되며, t-분포는 작은 표본을 이용할 때 더 넓고 현실적인 신뢰구간을 제공

## 2. 가설 검정과 신뢰 구간

### 통계적 실험의 중요성
* 데이터를 분석하지 않고 의사 결정을 내릴 경우, 많은 사람들이 직관이나 경험을 기반으로 결정 → 잘못된 결론을 내릴 위험이 큼
* 예) 신약 개발: 신약의 효과를 확인하려면 임상 실험(통계적 실험)을 통해 비교 검증 필요. 마케팅 광고 효과 분석: A/B 테스트를 통해 광고 효과를 검증해야 정확한 결론을 내릴 수 있음

### 유의성 검정(Significance Testing)
* "우리가 관측한 차이가 우연히 발생했을 확률"을 계산하는 과정
* 예) 신약 실험 — 기존 약 그룹(평균 감기 회복일수 5.2일, 표준편차 ±1.5일) vs 신약 그룹(4.9일, ±1.4일). "신약이 효과가 좋다"는 주장을 하기 위해서는 단순 평균 비교만으로는 차이가 크지 않아 보이므로, 이 차이가 우연이 아닐 확률을 계산해야 함
* 유의성 검정을 수행해서 p-value가 0.05보다 작다면, "우연이 아닐 확률이 높다" 즉, 신약이 효과가 있다고 판단

### 가설 설정
* **가설(Hypothesis):** 특정한 주장을 검증하기 위한 가정. 통계적 검정의 핵심은 "이 가설이 맞는지 아닌지 검증하는 과정"이며, 관측한 데이터에서 "차이가 유의미한가?"를 검증하는 과정에서 가설을 설정
* **귀무가설(Null Hypothesis, H0):** "차이가 없다" 또는 "효과가 없다"는 기본 가설
* **대립가설(Alternative Hypothesis, H1):** "차이가 있다" 또는 "효과가 있다"는 가설
* 예)
  * 신약 개발 — H0: "신약이 기존 약과 효과가 차이가 없다" / H1: "신약이 기존 약보다 효과가 더 좋다"
  * A/B 테스트 — H0: "기존 웹사이트와 새로운 웹사이트의 클릭률이 차이가 없다" / H1: "새로운 웹사이트가 기존 웹사이트보다 클릭률이 높다"
  * 교통 연구 — H0: "특정 지역의 승용차 이용률이 다른 지역과 차이가 없다" / H1: "특정 지역의 승용차 이용률이 다른 지역과 다르다"

### 신뢰 구간(Confidence Interval, CI)
* 신뢰구간은 모집단의 참된 평균(모수)을 포함할 것으로 예상되는 값의 범위. 표본에서 얻은 평균을 기반으로, 모집단의 평균이 어느 범위 안에 있을지를 추정하는 것
* 예) 95% 신뢰구간: "새로운 마케팅 전략이 고객 구매율을 평균 2~5% 증가시킬 것이다"라고 했을 때, "95% 확신을 가지고 구매율은 2~5% 사이"라고 말할 수 있음
* **신뢰 구간과 가설 검정의 관계:** 만약 신뢰구간이 0을 포함하지 않으면, 차이가 유의미하다고 판단
  * 신뢰구간이 [2%, 5%] → 0%가 포함되지 않음 → 유의미한 차이
  * 신뢰구간이 [-1%, 3%] → 0%가 포함됨 → 유의미한 차이 X

### 유의수준(α)
* 우리가 허용할 "우연한 결과"의 최대 확률을 의미. 보통 0.05(5%) 또는 0.01(1%)를 사용
* "5%의 확률로 우연히 발생한 결과를 허용하겠다"는 의미. 검정 결과가 귀무가설이 맞더라도, 5% 확률로 틀린 결론을 내릴 수 있음 (1종 오류를 5% 이내로 제한하겠다는 의미)
* 유의수준을 낮출수록(α = 0.01) 더 엄격한 검정을 수행하지만, 2종 오류위험 증가

| 구분 | H0 참일 때 | H0 거짓일 때 |
| --- | --- | --- |
| H0 기각 안함 | 옳은 결정 | 제2종 오류 |
| H0 기각 | 제1종 오류 | 옳은 결정 |

### t-검정 (t-test)
* 두 집단의 평균 차이가 통계적으로 유의미한 지를 검정하는 방법
* 특징: 모집단의 평균을 비교하는 검정 방법, 데이터가 정규성을 만족해야 함, 표본 수가 적더라도 비교적 정확한 결과를 제공
* 가설 설정 예: H0 "두 집단의 평균이 같다(차이가 없다)" / H1 "두 집단의 평균이 다르다(차이가 있다)"

### t-통계량과 p-value
```
t = (두 집단의 평균 차이) / (데이터의 퍼짐 정도) = (신호) / (잡음)
```
* 평균 차이가 크면 t ↑, 데이터가 들쭉날쭉(표준편차 ↑)하면 t ↓, 표본이 많을수록 t ↑
* **p-value:** 귀무가설이 참이라고 가정했을 때, 현재 관측된 결과보다 극단적인 결과가 나올 확률("이 차이가 단순한 우연일 가능성이 얼마나 되는지"). p-value가 작을수록 우리가 관측한 차이가 우연일 가능성이 낮아짐
* **해석 기준(유의수준 α=0.05일 때)**
  * p-value ≤ 0.05 → 귀무가설 기각 → "차이가 유의미하다"
  * p-value > 0.05 → 귀무가설 유지 → "차이가 우연일 가능성이 크다"

### 가설 검정(Hypothesis Testing)의 흐름
데이터 수집 → 데이터 전처리 → 정규성 검정 → 가설 검정 → 결과 해석

| 순서 | 설명 |
| --- | --- |
| 1. 가설 설정 | 귀무가설(H0)과 대립가설(H1) 설정 |
| 2. 유의수준 결정 | 보통 α = 0.05(5%) 사용 |
| 3. 검정 통계량 계산 | t-검정, ANOVA 등 적절한 방법 선택 |
| 4. p-value 확인 | p-value < 0.05이면 귀무가설 기각 |
| 5. 결론 도출 | 가설 채택 여부 결정 |

### 단측 검정 vs 양측 검정
| 유형 | 설명 | 가설 설정 |
| --- | --- | --- |
| 단측 검정 (One-tailed test) | 특정 방향으로 차이가 있는지를 검정 | H1: 차이 X vs H1: 한쪽 방향으로 차이 O |
| 양측 검정 (Two-tailed test) | 방향 고려 없이 단순히 차이가 있는지 검정 | H1: 차이 X vs H1: 차이 O |

```python
# 양측/단측 검정 예제 코드 (A구와 B구의 승용차 이용률 비교)
t_stat, p_value = stats.ttest_ind(a_district, b_district)
print(f"t-통계량: {t_stat:.4f}, p-value: {p_value:.4f}")
# 양측 검정 결과: t-통계량 -4.5129, p-value 0.0000 (p-value < 0.05) → 귀무가설 기각
# → "A구와 B구의 승용차 이용률에는 유의미한 차이가 있음"
```

### 독립 표본 t-검정
* t-검정 종류의 일종으로 **서로 독립적인 두 집단의 평균 비교**
* 사용 목적: 서로 다른 집단의 평균 차이를 비교하고 싶을 때, 두 집단이 서로 독립적이며 관측값이 중복되지 않을 때
* 예: A구와 B구 주민들의 승용차 이용률 차이 검정, 새로운 교육 프로그램이 남학생과 여학생의 성적에 차이를 미치는지 검정, 두 브랜드의 고객 서비스 만족도 차이 검정

```python
import pandas as pd
from scipy import stats

# 등분산 검정(Levene's test)으로 두 그룹 분산이 같은지 먼저 확인
levene_test = stats.levene(a_district, b_district)

if levene_test.pvalue > 0.05:
    t_stat, p_value = stats.ttest_ind(a_district, b_district, equal_var=True)   # 등분산 가정 t-검정
else:
    t_stat, p_value = stats.ttest_ind(a_district, b_district, equal_var=False)  # Welch's t-test

if p_value < 0.05:
    print("두 집단의 평균 차이가 유의미함 (귀무가설 기각)")
else:
    print("두 집단의 평균 차이가 유의미하지 않음 (귀무가설 유지)")
```

## 핵심 요약
* 모집단의 분포는 정규/균등/이항/포아송 등 다양하며, **중심극한정리**에 따라 표본 크기가 충분히 크면 표본평균의 분포는 모집단 분포 모양과 무관하게 정규분포에 가까워집니다.
* 모집단의 표준편차를 모를 때는 **t-분포**를 사용하며, 자유도가 작을수록 꼬리가 두꺼워 극단값 가능성을 더 현실적으로 반영합니다.
* 가설 검정은 **귀무가설(H0)/대립가설(H1) 설정 → 유의수준(α) 결정 → 검정통계량·p-value 계산 → 결론 도출**의 흐름을 따르며, `p-value < α`이면 귀무가설을 기각하고 "차이가 유의미하다"고 결론 내립니다.
* **독립표본 t-검정**은 서로 독립인 두 집단의 평균 차이를 비교할 때 사용하며, 등분산 여부(Levene's test)에 따라 일반 t-test 또는 Welch's t-test를 선택합니다.

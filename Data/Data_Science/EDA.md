# 탐색적 데이터 분석(EDA) 정리

**EDA(Exploratory Data Analysis)** 의 개념과, 정형(테이블) 데이터의 특징, 그리고 타이타닉 데이터를 예시로 한 정형 데이터 EDA 실전 과정을 정리한 문서입니다.

---

## 1. 탐색적 데이터 분석이란?

* **EDA(Exploratory Data Analysis):** 데이터를 살펴보고 데이터를 이해하기 위한 첫 과정
* **고전적인 통계학:** 적은 표본(샘플)을 가지고 더 큰 모집단에 대한 결론을 도출하기 위한 일련의 복잡한 과정
* **탐색적 데이터 분석(EDA)의 특징**
  * 데이터를 탐색하고, 데이터에 숨겨진 패턴을 찾기 위해 데이터를 시각화하고 요약하는 과정
  * 가정에 얽매이지 않음 (고전적 통계학에서는 주로 가정을 세움)
  * 이상치 탐지 (특이한 값)
  * 기술 통계 수행 (고전적 통계와 비슷)
  * EDA는 데이터 종류, 사용 모델에 따라 방향성이 다양함

### 데이터 분석 절차
```
문제 정의 → 데이터 수집 → 탐색적 데이터 분석 → 데이터 가공 → 모델 구현 → 모델 해석 → 모델 제출
```
* EDA는 "데이터에 대한 가설 혹은 의문 → 시각화·통계량·모델링을 통한 가설 검정 → 결론을 통해 다시 새로운 가설 혹은 문제"의 과정을 반복하며 진행됩니다.

### EDA 과정에서 파악할 요소
* 데이터 사이즈는 어느 정도인지
* 학습 데이터와 테스트 데이터는 어떻게 분리되어 있는지
* 결측값은 어느 정도인지
* 라벨이 있는 데이터라면 분포는 어떻게 되어있는지
* 데이터의 특이점이 있는지

## 2. 정형화된 데이터, 테이블 데이터의 이해

### 왜 굳이 데이터의 종류를 분류해야 할까?
데이터를 분석하고 예측을 모델링할 때, 시각화·해석·모델 결정에 데이터의 종류가 중요한 역할을 하기 때문입니다.

### 정형화된 데이터 요소
| 구분 | 유형 | 설명 | 예시 |
| --- | --- | --- | --- |
| 수치형 데이터 | 연속형 데이터 | 무한한 값을 가질 수 있는 수치데이터 | 풍속, 지속시간 등 |
| 수치형 데이터 | 이산형 데이터 | 특정한 정수값을 가질 수 있는 수치데이터 | 사건의 발생 빈도 등 |
| 범주형 데이터 | 명목형 데이터 | 순서의 의미가 없는 범주데이터 | TV 스크린 종류(플라즈마, LCD, LED 등), 도시명(대전, 부산, 서울 등) |
| 범주형 데이터 | 순위형 데이터 | 순서의 의미가 있는 범주데이터 | 수치로 나타낼 수 있는 평점(1,2,3,4,5점 등), 선호도(좋다, 중립, 싫다) |

### 테이블 데이터
* 데이터 분석에서 가장 대표적으로 사용하는 데이터 구조
* **용어 정리**
  * **DataFrame:** 통계와 머신러닝 모델에서 가장 기본이 되는 테이블 형태의 데이터 구조
  * **Feature:** 일반적으로 테이블의 각 열을 의미
  * **Output:** 데이터 과학 프로젝트의 목표는 대부분은 어떤 결과를 예측하는 것에 있음. 그 결과를 예측하기 위해 참조하는 열을 의미
  * **Record:** 일반적으로 테이블에서 볼 수 있는 하나의 행을 의미

### 테이블 데이터가 아닌 데이터 구조
* **시계열 데이터:** 동일한 변수 안에 연속적인 측정값을 갖는 데이터
* **공간 데이터:** 지도 제작과 위치 정보 분석에 사용되는 공간 데이터의 경우, 테이블 데이터보다 좀 더 복잡하고 다양함. 객체를 표현할 때는 위치 좌표가 데이터의 중심이 되며, 필드 정보는 공간을 나타내는 작은 단위들과 적당한 측정 기준 값에 중점을 둠
* **그래프 데이터:** 물리적 관계, 사회적 관계 그리고 다소 추상적인 관계들을 표현하기 위해 사용 (예: 페이스북이나 링크드인 같은 소셜네트워크의 그래프, 도로로 연결된 물류 중심지)

## 3. 정형 데이터 EDA 과정 (타이타닉 데이터 실습)

타이타닉 데이터를 사용해 승객 데이터에서 생존(Survived)에 영향을 주는 요인을 탐색합니다. **EDA는 모든 변수를 다 그리는 것이 아니라, 질문에 답하기 위해 변수를 선별하는 과정**입니다.

* 생존자 비율은 어느 정도인가?
* 어떤 특성이 생존과 강하게 연관되는가? (Pclass, Sex, Age, Fare, Family)
* 데이터 결측/왜곡(특히 Age, Cabin)이 분석에 어떤 영향을 주는가?
* 흐름: **EDA는 질문 → 요약(표) → 시각화 → 인사이트**의 반복

### 1) 데이터 확인
```python
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

plt.rcParams["font.family"] = "Malgun Gothic"
df = pd.read_csv("titanic.csv")
df.info()
```
* `Age`, `Cabin`, `Embarked`에 결측치가 있음을 확인. 특히 `Cabin`의 결측치가 상당히 많이 존재
* `PassengerId`는 단순 식별자(ID)이므로 생존 여부와의 관계에 유의미해 보이지 않음 → 추가적인 전처리나 특징 없이는 그대로 사용하기 어려움

| 컬럼명 | 설명 |
| --- | --- |
| PassengerId | 승객 ID |
| Survived | 생존 여부 (0: 사망, 1: 생존) |
| Pclass | 티켓 클래스 (1: 1등석, 2: 2등석, 3: 3등석) |
| Name | 승객 이름 |
| Sex | 성별 (male: 남성, female: 여성) |
| Age | 나이 |
| SibSp | 함께 탑승한 형제자매, 배우자 수 |
| Parch | 함께 탑승한 부모, 자녀의 수 |
| Ticket | 티켓 번호 |
| Fare | 운임 요금 |
| Cabin | 객실 번호 |
| Embarked | 탑승 항구 (C: 셰르부그, Q: 퀸스타운, S: 사우샘프턴) |

### 2) Feature Exploration
생존(Survived)과 관련 있을 것으로 예상되는 변수부터 탐색하고, 개별 변수의 분포를 통해 결측치·분포 형태·이상치 여부를 확인한 뒤, feature에 대한 분포 시각화를 진행하고, 이후 변수 간 관계 분석(Covariation)을 수행합니다.

**연속형 변수(Age, Fare) 분포**
* Age는 20~40대 구간에 승객이 많이 분포. 어린 나이와 고령 구간의 승객은 상대적으로 적고, 일부 결측치가 존재하여 전처리가 필요

**이산형 변수(SibSp, Parch) 분포**
* 대부분의 승객이 SibSp, Parch 값이 0 또는 1에 집중 (소수의 값에 빈도가 집중되어 있음)

**범주형 변수(Pclass, Sex, Embarked) 분포**
* Pclass는 3등급 승객의 비중이 가장 크고 1등급과 2등급 승객은 상대적으로 적음
* 남성 승객의 수가 여성 승객보다 많음
* 탑승 대부분은 S 항구에서 승선

**Survived (타겟 변수)**
```python
df["Survived"].value_counts()
# 0    549
# 1    342
```
0은 사망, 1은 생존을 의미하며, 수치상으로 사망자 수가 더 많은 것을 알 수 있습니다. 균형 잡힌 데이터가 아니므로 생존자 수 대비 다른 feature들과의 관계(Covariation) 확인이 필요합니다.

**Name**
* 대부분의 값이 고유값(unique)으로 구성. 이름 자체는 생존 여부를 직접적으로 설명하기 어려움
* 따라서 분석 및 모델링에 직접적인 feature로 사용하기는 부적절. 단, 호칭(Mr, Mrs, Miss 등)과 같은 정보는 파생 변수로 활용 가능성 존재

**Pclass ↔ Survived**
```python
df["Pclass"].value_counts()
```
* Survived를 기준으로 클래스별 생존율을 계산하면, 1등석 승객의 생존율이 가장 높고 등급이 낮아질수록 생존율이 감소하는 경향을 보임 → **Pclass는 생존 여부와 강한 관련성이 있는 변수**로 판단
* 사망한 탑승객 그래프에서 3클래스의 비율이 67.8%

**Sex ↔ Survived**
* 성별에 따라 생존율 차이가 크게 나타남. 여성 승객의 생존율이 남성보다 현저히 높음 (구조 시 여성을 우선으로 대피시켰을 것으로 추측)
* 성별은 생존 여부와 강한 연관성을 가지는 Feature로 판단됨

**Age ↔ Survived**
* 탑승객 나이 분포를 보면 20~40대가 가장 많음
* 10세 이하 연령대에서 상대적으로 높은 생존율을 보임
* 20~40대는 탑승객 수는 많지만 생존율은 평균 수준, 고령층은 표본 수가 적어 해석에 주의 필요
* Age는 생존 여부와 어느 정도 연관성이 있어 보이며, 특히 어린 연령대에서 차이가 관찰됨

**SibSp / Parch ↔ Survived**
* SibSp(함께 탑승한 형제자매·배우자 수, 본인 제외)=0(혼자 탑승한 승객)의 비중이 가장 크며 탑승 인원이 많아 사망자와 생존자 수 모두 크게 나타남. 동반 인원이 있는 경우 표본 수가 적어 생존 여부 차이 해석에 주의 필요
* Parch가 0인 승객(혼자 탑승한 경우)의 생존율이 상대적으로 낮게 나타남. SibSp와 유사한 형태의 분포를 보임
* SibSp와 Parch는 가족 동반 여부를 나타내는 변수로, 하나의 Feature로 통합하여 활용할 수도 있을 것으로 보임

**Embarked ↔ Survived**
* 탑승한 항구를 나타내는 Feature. S항구, C항구, Q항구 3종류의 항구가 있으며 결측값이 존재
* S항구 탑승객 수가 가장 많아, 사망자 수도 S 항구에서 가장 많이 나타남 (단, 이는 탑승객 수 자체가 많기 때문일 수 있으므로 항구별 생존율을 추가로 확인할 필요가 있음)
* S 항구에서 탑승한 승객 중 3등석 비중이 높은 것을 확인할 수 있는데, 이는 S 항구 탑승객의 사망률이 높아 보이는 현상이 객실 등급 분포와 관련 있을 가능성을 시사 → 분포 구조상 연관될 수 있음을 확인 (항구 × 동승자(SibSp, Parch), 클래스 × 동승자 관계도 함께 확인)

**Fare ↔ Survived**
* 탑승 요금을 나타내는 Feature. Fare 분포는 오른쪽으로 치우친 비대칭 분포를 보이며, 낮은 가격대에 관측치가 집중되어 있음
* 요금은 객실 등급(Pclass)과 연관이 있을 가능성이 있으며, 특히 3등석 탑승객 비중과의 관계를 추가로 확인할 필요가 있음
* Fare(요금) 자체만 보면 오른쪽으로 치우친 비대칭 분포를 보임. 높은 요금일수록 생존 확률이 높아지는 경향은 분명히 있으나, 이 영향은 Fare 자체의 효과라기보다는 객실 등급(Pclass) 및 사회적 위치를 반영한 결과일 수 있음

**Ticket / Cabin**
* Ticket(티켓 번호)에 대한 패턴은 찾기 어려움
* Cabin(객실 번호)은 총 891개의 데이터 중 204개의 데이터만 보유하고 있음 (결측치가 많고 객실 번호에 대한 패턴을 찾기 어려움)

## 핵심 요약
* EDA는 가정에 얽매이지 않고 데이터를 시각화·요약하여 **가설 → 검정 → 새로운 가설**을 반복하는 탐색 과정이며, 목적은 "모든 변수를 그리는 것"이 아니라 "질문에 답할 변수를 선별하는 것"입니다.
* 데이터는 수치형(연속형/이산형)과 범주형(명목형/순위형)으로 나눌 수 있고, 테이블 데이터 외에도 시계열·공간·그래프 데이터 등 다양한 구조가 존재합니다.
* 타이타닉 예제에서는 `Pclass`, `Sex`, `Age`, `Fare`가 생존 여부와 뚜렷한 관련을 보였고, `SibSp`/`Parch`는 가족 동반 여부로 묶어 파생 변수로 활용할 수 있으며, `PassengerId`·`Ticket`·`Cabin`(결측 과다)은 그대로 사용하기 어려운 변수로 확인되었습니다.

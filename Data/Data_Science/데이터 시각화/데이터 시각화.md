# 데이터 시각화 정리

탐색적 데이터 분석에 필요한 시각화 개념과, 파이썬의 대표적인 시각화 라이브러리인 **Matplotlib · Seaborn · Plotly**의 특징과 사용법을 정리한 문서입니다.

---

## 1. 시각화 기본 개념

### 데이터 시각화의 필요성과 목적
* 데이터를 쉽게 이해할 수 있도록 돕는다
* 데이터 간의 패턴과 추세를 발견한다
* 탐색적 데이터 분석(EDA)에 도움을 준다
* (주의) 데이터를 왜곡하여 특정 메시지를 전달하는 용도가 되어서는 안 됨

### 알맞은 시각화 방식을 선택해야 하는 이유
같은 데이터라도 그래프 종류(막대, 히스토그램, 버블차트 등)에 따라 전달되는 인상이 달라지므로, 데이터의 성격과 분석 목적에 맞는 그래프를 선택해야 합니다.

### 시각화 유형과 용도
| 시각화 유형 | 설명 | 용도 |
| --- | --- | --- |
| 히스토그램 (Histogram) | 연속형 데이터의 도수 분포를 나타냄 | 데이터 분포 확인, 특정 값이 많이 나타나는지 분석 |
| 막대 그래프 (Bar Plot) | X축에 범주형 데이터, Y축에 연속형 데이터를 배치하여 특정 범주별 평균/합계를 비교 | 범주별 데이터 비교, 그룹별 평균 또는 합계 비교 |
| 산포도 (Scatter Plot) | 두 개의 연속형 변수 간 관계를 나타내는 산점도 | 변수 간 관계 분석, 상관관계 확인, 데이터 분포에 따른 패턴 파악 |
| 선 그래프 (Line Plot) | 시계열 데이터를 시각화하는 그래프. X축에 시간 요소(년/월/일 등), Y축에 연속형 데이터 배치 | 시간에 따른 데이터 변화, 추세(Trend) 파악 |
| 박스 플롯 (Box Plot) | 데이터의 분포와 이상치를 시각화. 중앙값, 사분위수, 이상치를 표시 | 데이터 분포 비교, 이상치 탐지 |
| 바이올린 플롯 (Violin Plot) | 박스 플롯과 KDE(커널 밀도 추정)를 결합한 형태 | 데이터의 밀도와 분포 형태를 더욱 직관적으로 표시 |
| 히트맵 (Heatmap) | 행렬 형태의 데이터를 색상으로 표현하여 관계를 시각화 | 상관관계 분석, 행렬 데이터 시각화 |
| 버블 차트 (Bubble Chart) | 산포도와 유사하지만, 점의 크기로 추가적인 변수를 표현 | 다차원 데이터 시각화, 변수 간 관계 분석 |

* **히스토그램**은 분포 확인, 특정 값이 많이 나타나는지 분석할 때 주로 사용
* **가로/세로 막대 그래프**는 항목별 차이를 비교할 때 자주 사용 (긴 텍스트 라벨은 가독성 좋게 가로형으로)
* **산포도**는 복수의 변수를 비교하거나 상관관계를 파악할 때 자주 사용
* **선 그래프**는 시계열 변화를 나타낼 때 자주 사용
* **박스 플롯**은 하나 이상의 연속형 변수의 분포와 이상값을 시각화
* **바이올린 플롯**은 박스 플롯 + 커널 밀도 추정(KDE)을 결합한 형태로 분포의 형태와 밀도를 함께 시각화
* **히트맵**은 이차원 형태의 데이터 값의 크기를 색상 농도로 시각화해 패턴 및 상관관계를 파악
* **버블 차트**는 산포도에 크기라는 차원(변수)을 추가한 형태

## 2. Matplotlib을 활용한 시각화

### 장단점
* **장점:** 유연성(모든 종류의 플롯 가능, 세밀한 커스터마이징), 넓은 사용자층과 문서(풍부한 자료와 커뮤니티 지원), 정교한 제어(그래프의 모든 요소 조정 가능)
* **단점:** 복잡성(간단한 작업도 많은 코드 필요), 기본 스타일(추가 스타일링이 필요할 수 있음)

### 시각화 구성요소 (Anatomy of a Figure)
Matplotlib의 시각화는 다음과 같은 계층 구조로 구성됩니다.
* **Figure:** 그림을 그리기 위한 캔버스(Canvas) 역할. 그림판의 크기 등을 조절
* **Axes:** 실제 그림을 그리는 매소드들을 가짐. x축, y축, Title 등의 속성 설정
* 하나의 Figure 안에 여러 개의 Axes(서브플롯)를 배치할 수 있음

```python
import matplotlib.pyplot as plt

# 선 그래프를 그리기 위한 기본 사용법
plt.plot([1, 2, 3], [2, 4, 6])   # x 값 [1,2,3]과 y값 [2,4,6]을 이용하여 그래프를 그림
plt.title('Hello plot')
plt.show()
```

### pyplot 기본 사용법
```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4])              # 하나의 값 목록만 넘기면 y축은 자동으로 인덱스[0,1,2,3...]
plt.ylabel('some numbers')
plt.plot([1, 2, 3, 4], [1, 4, 9, 16], 'ro')   # x값, y값 지정 + 빨간색 원형 마커
plt.axis([0, 6, 0, 20])             # 축 범위 설정 (x축: 0~6, y축: 0~20)
plt.show()
```

### 여러 개의 Plot을 가지는 Figure (Subplots)
```python
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 6))   # 1행 2열 서브플롯

# 여러 axes를 하나의 figure로 표출
plt.subplot(2, 2, 1)   # 2행 2열 중 첫 번째 위치(왼쪽 위)에 그래프 삽입
plt.plot(t1, f(t1), 'b')
plt.subplot(2, 2, 2)   # 2행 2열 중 두 번째 위치(오른쪽 위)
plt.plot(t2, f(t2), 'k')
```
* **Figure:** Matplotlib에서 전체 플롯이 그려지는 "캔버스"와 같은 역할
* **Axes:** Matplotlib에서 실제 데이터가 그려지는 영역을 의미

### 그래프 formatting 변경
```python
import numpy as np
import matplotlib.pyplot as plt

x_value = np.arange(0, 100)
y_value = 2 * x_value

plt.plot(x_value, y_value, color='green')
plt.xlabel('x axis')
plt.ylabel('y axis')

plt.xticks(ticks=np.arange(0, 100, 5), rotation=90)   # x축 눈금 간격/회전 설정
plt.xlim(0, 50)    # x축 범위 설정 (0~50)
plt.ylim(0, 100)   # y축 범위 설정 (0~100)

plt.legend()         # 범례 추가 (plot에 label 지정 필요)
plt.title('Hello Ssafy')
plt.show()
```
* `color`, `marker`, `linestyle`, `linewidth`, `markersize` 등 다양한 스타일 요소를 조합해 활용할 수 있습니다.
```python
plt.plot(x_value, y_value, color='red', marker='o', linestyle='dashed', linewidth=2, markersize=10)
```

### y축 scale 변경
```python
plt.subplot(221); plt.plot(x, y); plt.yscale('linear'); plt.title('Linear')
plt.subplot(222); plt.plot(x, y); plt.yscale('log'); plt.title('Log')
plt.subplot(223); plt.plot(x, y); plt.yscale('symlog', linthresh=0.01); plt.title('Symmetric log')
plt.subplot(224); plt.plot(x, y); plt.yscale('logit'); plt.title('Logit')
```

## 3. Seaborn을 활용한 시각화

### 장단점
* **장점:** 간결함(적은 코드로 세련된 시각화 가능), 기본 스타일(매력적인 기본 스타일 제공), 데이터프레임 친화적(Pandas와 잘 통합됨), 고급 통계 기능(통계적 시각화 쉽게 구현)
* **단점:** 제한된 커스터마이징(세부적인 조정이 어려움), 유연성 부족(특정 그래프나 기능에 한계)

### 함수 구조: Figure-level vs Axes-level
Seaborn의 함수는 크게 두 레벨로 나뉩니다.
* **Figure-level 함수:** Figure 전체를 관리 (relplot, displot, catplot)
* **Axes-level 함수:** 개별 Axes에서 하나의 플롯을 그리는 데 사용 (scatterplot/lineplot, histplot/kdeplot/ecdfplot/rugplot, stripplot/swarmplot/boxplot/violinplot/pointplot/barplot 등)

### 히스토그램 / bar 그래프
```python
import seaborn as sns
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = 'Malgun Gothic'
df = sns.load_dataset('tips')

plt.figure(figsize=(8, 5))
sns.histplot(df['total_bill'], bins=20, kde=True, color='#ff774c')
plt.title('Total Bill 분포 히스토그램')
plt.xlabel('Total Bill ($)', fontsize=12)
plt.ylabel('빈도 (Frequency)', fontsize=12)
plt.show()

colors = ['#8fff4d', '#ff774c', '#4d8fff', '#a2ca4c', '#48d720']
plt.figure(figsize=(8, 5))
sns.barplot(x='day', y='total_bill', data=df, hue='day', palette=colors)
plt.title('요일별 총합 요금 (색상 적용)')
```

### Heatmap / 산포도(scatterplot) / pairplot
```python
# 요일 vs 시간대별 Total bill 평균을 히트맵으로 표현
pivot_table = df.pivot_table(values='total_bill', index='day', columns='total_bill', aggfunc='mean')
sns.heatmap(pivot_table, cmap='coolwarm', annot=True, fmt='.1f', linewidths=0.5)

# Axes-level 함수 사용(scatterplot)
sns.scatterplot(data=df, x='total_bill', y='tip', hue='smoker', style='time', palette='deep', markers=['o', 'X'])

# Figure-level 함수(subplot 자동 구성)
sns.relplot(data=df, x='total_bill', y='tip', hue='sex', col='time', row='smoker', kind='scatter')
```

## 4. Plotly를 활용한 시각화

### 장단점
* **장점:** 상호작용성(상호작용 가능한 그래프 기본 제공), 웹 통합(웹 기반 시각화에 최적화), 3D 및 지리적 시각화(고급 시각화를 간단히 구현), 시각적 미학(세련된 기본 그래프 제공)
* **단점:** 학습 곡선(고급 기능 활용을 위해 학습 필요), 대규모 데이터 처리 한계(성능 문제 발생 가능), 복잡한 커스터마이징(세밀한 조정이 복잡할 수 있음)

### 기본 사용 예시
```python
import plotly.express as px
import plotly.io as pio
pio.renderers.default = 'browser'   # vscode 등 미지원 환경 설정

# 데이터 필터링 (Oceania 대륙 데이터만 필터링)
df = px.data.gapminder()
df_2007 = df.query("continent=='Oceania'")

# 그래프 그리기
fig = px.line(df_2007, x='year', y='lifeExp', color='country')

# 마커 추가 (점 + 선)
fig.update_traces(mode='markers+lines')
fig.show()
```

### plotly 제공 템플릿 활용
```python
import plotly.express as px

df = px.data.gapminder()
for template in ["plotly", "plotly_white", "plotly_dark", "ggplot2", "seaborn", "simple_white", "none"]:
    fig = px.scatter(df,
        x="gdpPercap", y="lifeExp", size="pop", color="continent",
        log_x=True, size_max=60,
        template=template, title=f"gapminder 2007 ({template})")   # 여러 템플릿을 일괄 적용
    fig.show()
```

## 핵심 요약
* 데이터 시각화는 데이터의 패턴/추세를 발견하고 분석 결과를 쉽게 전달하기 위한 도구이며, 데이터 종류(연속형/범주형/시계열/관계형)에 맞는 그래프를 선택하는 것이 중요합니다.
* **Matplotlib**은 Figure–Axes 계층 구조를 기반으로 모든 요소를 세밀하게 제어할 수 있는 저수준 라이브러리입니다.
* **Seaborn**은 Matplotlib 위에서 동작하며 Figure-level/Axes-level 함수 체계로 통계적 시각화를 적은 코드로 세련되게 구현할 수 있습니다.
* **Plotly**는 상호작용(인터랙티브) 웹 시각화에 강점이 있으며, `plotly.express`로 다양한 템플릿을 손쉽게 적용할 수 있습니다.

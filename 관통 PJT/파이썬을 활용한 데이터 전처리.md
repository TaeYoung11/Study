# 관통 PJT 파이썬을 활용한 데이터 전처리 정리

외부 **API**로부터 데이터를 가져오는 방법, 텍스트를 음성으로 변환하는 **gTTS**, AI 도구와 데이터를 연결하는 **MCP**, 그리고 관통 프로젝트 진행 방식을 정리한 문서입니다.

---

## 1. API

* **API(Application Programming Interface):** 서로 다른 프로그램이 정해진 규칙으로 데이터를 주고받을 수 있도록 만든 인터페이스
* 웹에서는 주로 HTTP 요청을 통해 **REST API**를 호출하고, 응답으로 JSON 형태의 데이터를 받는 방식이 일반적

```python
import requests

url = "https://api.example.com/weather"
params = {"city": "Seoul", "key": "API_KEY"}

response = requests.get(url, params=params)   # GET 요청

if response.status_code == 200:                # 정상 응답
    data = response.json()                      # JSON 파싱
else:
    print(f"요청 실패: {response.status_code}")
```

* **상태 코드(Status Code):** `200`(성공), `4XX`(클라이언트 오류, 잘못된 요청/인증 실패), `5XX`(서버 오류)
* API마다 인증 방식(API Key, OAuth 등)과 요청 제한(Rate Limit)이 다르므로 공식 문서를 확인하고 사용해야 함

## 2. gTTS (Google Text-to-Speech)

* 파이썬에서 텍스트를 음성 파일(mp3)로 변환해주는 구글의 TTS 라이브러리
* 수집/가공한 텍스트 데이터를 음성 콘텐츠로 만드는 등의 부가 기능 구현에 활용 가능

```python
from gtts import gTTS

text = "수집한 데이터를 음성으로 변환합니다."
tts = gTTS(text=text, lang="ko")   # 언어 코드 지정 (ko: 한국어)
tts.save("output.mp3")
```

* `lang` 파라미터로 다양한 언어의 음성 합성을 지원하며, 별도의 딥러닝 모델 학습 없이 간단하게 TTS 기능을 붙일 수 있음

## 3. MCP (Model Context Protocol)

* AI 모델(LLM)이 외부 도구·데이터 소스와 표준화된 방식으로 상호작용할 수 있도록 정의된 프로토콜
* 기존에는 AI에 새로운 데이터/도구를 연결하려면 각각 커스텀 연동 코드를 작성해야 했지만, MCP는 **서버(Server)** 가 제공하는 기능(도구, 리소스)을 **클라이언트(Client, AI 모델)** 가 공통 규격으로 호출할 수 있게 함

### 핵심 구성 요소

| 구성 요소 | 역할 |
| --- | --- |
| **MCP Server** | 특정 데이터/기능(파일 시스템, DB, 외부 API 등)을 도구(Tool) 형태로 노출 |
| **MCP Client** | AI 모델(호스트 애플리케이션)이 MCP 서버가 제공하는 도구 목록을 조회하고 호출 |
| **Tool** | 서버가 제공하는 실행 가능한 기능 단위 (예: "파일 읽기", "DB 조회") |

```python
# 개념 예시: MCP 서버가 하나의 Tool을 등록하는 형태
from mcp.server import Server

server = Server("data-tool-server")

@server.tool()
def search_data(keyword: str) -> str:
    """키워드로 로컬 데이터를 검색해 반환하는 도구"""
    return search_in_local_db(keyword)
```

* MCP를 사용하면 AI 모델이 **"어떤 도구가 있는지, 어떻게 호출하는지"** 를 표준화된 방식으로 알 수 있어, 새로운 데이터 소스를 연결할 때마다 매번 커스텀 통합 코드를 작성할 필요가 줄어듦

---

## 4. 관통 프로젝트 안내

* 지금까지 배운 **데이터 수집(Git, 파일 시스템, JSON, API) → 가공(생성형 AI 요약, gTTS, MCP)** 흐름을 하나로 엮어, 스스로 데이터를 수집하고 가공하는 미니 프로젝트를 직접 설계하고 구현
* 프로젝트 진행 시 확인할 사항
  1. 어떤 데이터를 어디서(API/크롤링/파일) 수집할 것인가
  2. 수집한 데이터를 어떤 형식(JSON 등)으로 저장할 것인가
  3. 생성형 AI/TTS 등 후처리를 어떤 기능에 적용할 것인가

---

## 핵심 요약
* **API**는 `requests` 라이브러리로 HTTP 요청을 보내고 JSON 응답을 받는 방식으로 외부 데이터를 수집하는 표준적인 방법이다.
* **gTTS**는 텍스트를 음성 파일로 변환해주는 간단한 TTS 라이브러리로, 데이터 가공 결과물에 음성 기능을 손쉽게 추가할 수 있다.
* **MCP**는 AI 모델이 외부 도구/데이터 소스를 표준화된 방식(Server가 제공하는 Tool을 Client가 호출)으로 사용할 수 있게 하는 프로토콜로, AI-도구 연동의 커스텀 코드를 줄여준다.
* 관통 프로젝트는 이 단계까지 배운 수집·가공 기술을 조합해 스스로 파이프라인을 설계하고 구현해보는 실습이다.

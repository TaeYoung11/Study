# 관통 PJT 반응형 웹 사이트 구현 프로젝트 정리

**Web Font**를 활용한 타이포그래피 커스터마이징, **생성형 AI와 함께 코딩하는 방법(Programming with AI)**, 그리고 **Figma**와 생성형 AI를 활용해 웹 페이지를 구현하는 과정을 정리한 문서입니다.

---

## 1. Web Font

### 웹 폰트를 쓰는 이유

* 사용자의 기기에 특정 폰트가 설치되어 있지 않아도, 웹 서버(또는 CDN)에 있는 폰트 파일을 내려받아 **모든 사용자에게 동일한 디자인**을 보여줄 수 있음

### 적용 방법

```css
/* 1) @font-face로 직접 폰트 파일 선언 */
@font-face {
    font-family: "Pretendard";
    src: url("./fonts/Pretendard-Regular.woff2") format("woff2");
    font-weight: 400;
}

/* 2) 구글 폰트 등 외부 CDN 링크 활용 (HTML <head>에 <link> 추가 후) */
body {
    font-family: "Pretendard", "Noto Sans KR", sans-serif;
}
```

* `font-weight`, `font-style`별로 각각 `@font-face`를 선언하면 굵기/기울임별로 별도의 폰트 파일을 매핑할 수 있음
* `woff2` 포맷은 압축률이 높아 로딩 속도에 유리해 웹 폰트의 사실상 표준 포맷으로 널리 사용됨

## 2. Programming with AI

생성형 AI(코딩 어시스턴트)를 웹 개발 워크플로우에 접목하는 방법을 다룹니다.

* **코드 생성/보완:** 마크업/스타일 초안을 자연어로 요청해 빠르게 뼈대를 잡고, 세부 사항을 직접 다듬는 방식으로 협업
* **디버깅 보조:** 에러 메시지나 의도한 동작과 다른 부분을 설명하면, 원인 후보와 수정 방향을 제시받아 문제 해결 속도를 높임
* **효율적인 프롬프트 작성 원칙**
  1. 목표(무엇을 만들고 싶은지)와 제약 조건(사용 기술, 디자인 톤)을 구체적으로 명시
  2. 기존 코드/컨텍스트를 함께 제공해 일관된 스타일로 결과를 받기
  3. 생성된 코드는 그대로 사용하지 않고, 반드시 직접 검토하고 이해한 뒤 반영

> AI는 초안을 빠르게 만들어주는 협업자일 뿐, 최종 코드에 대한 이해와 책임은 개발자 본인에게 있다는 점을 항상 유의해야 합니다.

## 3. Figma와 생성형 AI를 활용한 웹 페이지 구현

### Figma 활용

* **디자인 소프트웨어 Figma**로 와이어프레임/목업을 제작해, 실제 코드를 작성하기 전에 레이아웃과 컴포넌트 구조를 시각적으로 확정
* Figma의 **Auto Layout, Component, Variants** 기능을 활용하면 반응형 디자인에 필요한 요소(간격, 정렬, 상태별 스타일)를 미리 설계할 수 있음

### Figma 디자인 → 코드로 옮기는 흐름

1. Figma에서 화면별 디자인(데스크톱/모바일 등 반응형 브레이크포인트 포함)을 제작
2. 각 요소의 스타일 값(색상, 폰트, 간격)을 **디자인 토큰**처럼 정리
3. 생성형 AI에게 디자인 설명(또는 캡처 이미지, Figma 링크)을 전달해 HTML/CSS 초안을 생성 요청
4. 생성된 코드를 실제 브라우저에서 확인하며 반응형 breakpoint, 접근성 등을 다듬어 완성

### 반응형 구현 시 확인 포인트

* Figma에서 설계한 **브레이크포인트(모바일/태블릿/데스크톱)** 가 실제 CSS 미디어 쿼리로 정확히 반영되었는지 확인
* 웹 폰트, 이미지 등 리소스가 화면 크기에 따라 적절한 크기로 로드되는지 확인

## 핵심 요약
* **Web Font**는 `@font-face` 또는 CDN 링크로 폰트 파일을 웹에서 직접 제공해, 사용자 기기와 무관하게 일관된 타이포그래피를 구현하는 방법이다.
* **Programming with AI**는 생성형 AI를 코드 초안 작성·디버깅 보조 도구로 활용하되, 결과 코드를 반드시 직접 검토하고 이해하는 것이 핵심 원칙이다.
* **Figma**로 반응형 레이아웃을 먼저 설계한 뒤, 생성형 AI로 초안 코드를 빠르게 생성하고 실제 브라우저에서 반응형 동작을 검증하며 완성하는 것이 이번 프로젝트의 핵심 워크플로우이다.

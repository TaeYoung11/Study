# 관통 PJT 파이썬을 활용한 데이터 수집 정리

관통 프로젝트의 첫 단계로, 프로젝트 협업의 기본이 되는 **Git**과 **파일 시스템**, 데이터 교환 포맷인 **JSON**, 그리고 **생성형 AI를 활용한 데이터 요약**까지 정리한 문서입니다.

---

## 1. Git

### Git이 필요한 이유

* 여러 명이 함께 프로젝트를 진행할 때, 코드의 변경 이력을 추적하고 서로 다른 작업 내용을 안전하게 합치기 위해 사용하는 **분산 버전 관리 시스템(DVCS)**
* 로컬 저장소(Repository)에서 변경 사항을 커밋으로 남기고, 원격 저장소(GitHub 등)와 주고받으며 협업

### 기본 작업 흐름

```bash
git init                      # 로컬 저장소 초기화
git add <file>                 # 변경 사항을 스테이징 영역에 추가
git commit -m "메시지"          # 스테이징된 변경 사항을 커밋으로 기록

git remote add origin <url>    # 원격 저장소 연결
git push origin main            # 원격 저장소에 반영
git pull origin main             # 원격 저장소의 변경 사항 가져오기
```

* **작업 트리(Working Directory) → 스테이징 영역(Staging Area) → 저장소(Repository)** 3단계 구조로 변경 사항을 관리

## 2. 파일 시스템

* 파이썬에서 데이터를 수집·저장할 때는 로컬 파일 시스템에 접근해 읽고 쓰는 작업이 기본이 됨

```python
# 파일 쓰기 / 읽기
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("수집한 데이터")

with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 디렉터리 및 경로 다루기
import os
os.makedirs("data", exist_ok=True)     # 폴더 생성 (이미 있으면 무시)
os.path.join("data", "result.json")     # OS에 상관없이 안전한 경로 결합
os.listdir("data")                       # 폴더 내 파일 목록 조회
```

* `with` 구문을 사용하면 파일을 닫는(`close()`) 처리를 자동으로 해주어, 예외가 발생해도 파일이 안전하게 닫힘

## 3. JSON

* **JSON(JavaScript Object Notation)**: 키-값 쌍으로 이루어진, 언어에 독립적인 경량 데이터 교환 포맷
* 파이썬의 dict/list와 구조가 거의 동일해 변환이 자연스러움 (API 응답, 설정 파일 등에서 널리 사용)

```python
import json

data = {"name": "SSAFY", "year": 2026}

# 파이썬 객체 -> JSON 문자열/파일
json_str = json.dumps(data, ensure_ascii=False)     # 문자열로 변환 (한글 깨짐 방지)
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)  # 파일로 저장 (indent: 들여쓰기)

# JSON 문자열/파일 -> 파이썬 객체
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
```

* `ensure_ascii=False`: 한글 등 비-ASCII 문자를 유니코드 이스케이프(`\uXXXX`) 없이 그대로 저장
* `indent`: 사람이 읽기 좋은 형태로 들여쓰기하여 저장

## 4. 생성형 AI를 활용한 데이터 요약

* 수집한 대량의 텍스트 데이터를 생성형 AI(LLM) API에 전달해 **핵심 내용을 요약**하거나 **구조화된 형태(JSON 등)로 정리**하는 데 활용
* 일반적인 흐름: **원본 데이터 수집 → 전처리(불필요한 텍스트 제거) → 프롬프트 구성 → API 호출 → 응답 파싱 및 저장**

```python
import openai   # 예시: 생성형 AI API 클라이언트

def summarize(text):
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "다음 글을 3줄로 요약해줘."},
            {"role": "user", "content": text},
        ],
    )
    return response.choices[0].message.content
```

* 프롬프트에 **원하는 출력 형식(요약 글머리, JSON 스키마 등)** 을 명확히 지시할수록 후속 처리(파싱)가 쉬워짐
* API로 받은 응답은 다시 JSON/파일로 저장해 다음 단계(전처리, 분석)의 입력 데이터로 활용

---

## 핵심 요약
* **Git**은 작업 트리 → 스테이징 영역 → 저장소 흐름으로 변경 이력을 관리하는 분산 버전 관리 시스템으로, 관통 프로젝트 협업의 기본 도구이다.
* 파이썬의 **파일 시스템** 다루기(`open`, `os` 모듈)는 수집한 데이터를 로컬에 안전하게 저장·조회하는 데 필수적이다.
* **JSON**은 파이썬 dict/list와 구조가 유사한 경량 데이터 포맷으로, `json.dump/load`로 손쉽게 파이썬 객체와 상호 변환할 수 있다.
* **생성형 AI**를 데이터 수집 파이프라인에 연결하면, 수집한 원본 텍스트를 요약하거나 원하는 형식으로 구조화하는 후처리 단계를 자동화할 수 있다.

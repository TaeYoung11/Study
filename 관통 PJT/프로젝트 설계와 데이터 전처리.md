# 관통 PJT 프로젝트 설계와 데이터 전처리 정리

관통 프로젝트의 후반부 시작 단계로, 새로운 프로젝트 주제를 **기획하고 설계**하는 과정과, 수집한 원본 데이터를 서비스에 사용할 수 있는 형태로 다듬는 **데이터 가공 및 저장** 과정을 정리한 문서입니다.

---

## 1. 프로젝트 기획과 설계

### 기획 단계에서 정의할 것들

1. **문제 정의:** 이 프로젝트로 해결하려는 문제/제공하려는 가치가 무엇인지 한 문장으로 정의
2. **핵심 기능(Feature) 목록화:** 필수 기능(MVP)과 추가 기능을 구분
3. **데이터 흐름 설계:** 어떤 데이터를 어디서 수집해서, 어떻게 가공하고, 어떤 형태로 사용자에게 보여줄지 정의
4. **화면 설계(와이어프레임):** 각 기능이 어떤 화면/컴포넌트로 구현될지 대략적인 레이아웃 설계

### 설계 산출물

| 산출물 | 내용 |
| --- | --- |
| **요구사항 명세서** | 기능별 상세 요구사항, 우선순위 |
| **ERD** | 데이터 모델(테이블/관계) 설계 |
| **API 명세서** | 프론트엔드-백엔드 간 주고받을 요청/응답 형식 |
| **와이어프레임** | 화면 구성과 사용자 흐름(User Flow) |

> 설계 단계에서 API 명세서를 먼저 확정해두면, 프론트엔드와 백엔드 개발을 병렬로 진행할 수 있어 팀 협업 효율이 크게 올라갑니다.

---

## 2. 데이터 가공 및 저장

### 원본 데이터를 서비스용 데이터로 가공하기

* 앞서 수집한 원본 데이터(API 응답, 크롤링 결과 등)는 보통 그대로 사용하기 어려우며, 다음과 같은 가공 과정이 필요함
  1. **정제:** 결측치/이상치/중복 데이터 제거
  2. **정규화:** 날짜, 단위, 카테고리 값 등을 일관된 형식으로 통일
  3. **구조화:** 서비스의 DB 스키마(모델)에 맞는 형태로 변환

```python
import json

def clean_and_transform(raw_items):
    cleaned = []
    for item in raw_items:
        if not item.get("title"):        # 필수 값 없는 데이터는 제외
            continue
        cleaned.append({
            "title": item["title"].strip(),
            "price": int(item.get("price", 0)),
            "category": item.get("category", "기타").lower(),
        })
    return cleaned
```

### 저장 방식 선택

| 방식 | 적합한 상황 |
| --- | --- |
| **관계형 DB (PostgreSQL 등)** | 데이터 간 관계가 명확하고, 정합성(트랜잭션)이 중요한 경우 |
| **파일(JSON/CSV)** | 프로토타입 단계, 소규모 정적 데이터 |
| **초기 데이터 적재 (Fixtures/Seed)** | 가공이 끝난 데이터를 서비스 DB에 초기값으로 일괄 등록 |

```python
# Django의 관리 명령어(management command)로 가공된 데이터를 DB에 적재하는 예시
from django.core.management.base import BaseCommand
from books.models import Book

class Command(BaseCommand):
    def handle(self, *args, **options):
        with open("cleaned_books.json", encoding="utf-8") as f:
            data = json.load(f)
        Book.objects.bulk_create([Book(**item) for item in data])   # 대량 데이터 일괄 저장
```

* `bulk_create`처럼 대량 삽입에 최적화된 ORM 기능을 활용하면, 데이터 건수가 많아도 초기 적재 시간을 크게 단축할 수 있음

## 핵심 요약
* **프로젝트 기획과 설계** 단계에서는 문제 정의 → 기능 목록화 → 데이터 흐름 설계 → 화면 설계 순으로 산출물(요구사항 명세서, ERD, API 명세서, 와이어프레임)을 준비해 이후 개발을 병렬화할 수 있게 한다.
* **데이터 가공**은 정제(결측치/이상치 제거) → 정규화(형식 통일) → 구조화(서비스 스키마에 맞춤) 순으로 진행한다.
* 가공이 끝난 데이터는 관계형 DB에 `bulk_create` 등을 활용해 초기 데이터로 일괄 저장하며, 이후 실제 서비스 로직에서 이 데이터를 활용하게 된다.

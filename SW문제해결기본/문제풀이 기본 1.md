# SW문제해결기본 문제풀이 기본 1 정리

1차원/2차원 리스트를 활용하는 SWEA 기본 문제풀이 4문제(**초심자의 회문 검사**, **파리 퇴치**, **풍선팡**, **Ladder1**)를 정리한 문서입니다.

---

## 1. 1989. 초심자의 회문 검사

### 문제
"level"과 같이 거꾸로 읽어도 제대로 읽은 것과 같은 문장이나 낱말을 회문(回文, palindrome)이라 한다.
단어를 입력 받아 회문이면 1을 출력하고, 아니라면 0을 출력하는 프로그램을 작성하라.

### 제약사항
* 각 단어의 길이는 3 이상 10 이하

### 입력 / 출력 예시
| 입력 | 출력 |
| --- | --- |
| 3 | |
| level | #1 1 |
| samsung | #2 0 |
| eye | #3 1 |

### 접근 아이디어
* 문자열을 뒤집은 결과(`s[::-1]`)와 원본 문자열이 같은지 비교하여 회문 여부를 판별할 수 있다.

## 2. 2001. 파리 퇴치

### 문제
N×N 배열 안의 숫자는 해당 영역에 존재하는 파리의 개수를 의미한다.
M×M 크기의 파리채를 한번 내려쳐서 최대한 많은 파리를 죽이고자 한다.
죽은 파리의 개수를 구하라!

예를 들어 N=5, M=2일 경우 위 예제의 정답은 490마리가 된다.

```
1  3  3  6  7
8 [13][9] 12 8
4 [16][11] 12 6
2  4  1  23 2
9 13  4  7  3
```
* (예시: 2행~3행, 2열~3열 영역 `13+9+16+11 = 49`가 M×M 부분합 후보 중 하나)

### 제약사항
* 5 ≤ N ≤ 15, 2 ≤ M ≤ N
* 각 영역의 파리 개수는 30 이하

### 입력 / 출력 예시
| 입력 | 출력 |
| --- | --- |
| 5 2 | |
| 1 3 3 6 7 | |
| 8 13 9 12 8 | |
| 4 16 11 12 6 | |
| 2 4 1 23 2 | |
| 9 13 4 7 3 | #1 49 |

### 접근 아이디어
* N×N 배열에서 가능한 모든 M×M 부분 영역의 합을 구하고, 그 중 최댓값을 찾는 완전 탐색(브루트포스) 문제.
* 2차원 리스트 순회와 부분 영역 합 계산(중첩 반복문)을 활용한다.

## 3. 9490. 풍선팡

### 문제
종이 꽃가루가 들어있는 풍선이 M개씩 N개의 줄에 붙어있고, 어떤 풍선을 터뜨리면 안에 든 종이 꽃가루 개수만큼 상하 좌우의 풍선이 추가로 터지게 되는 게임이 있다.

예를 들어 풍선에 든 꽃가루가 1개일 때, 가운데 풍선을 터뜨리면 상하좌우의 풍선이 추가로 1개씩 터지면서 총 5개의 꽃가루가 날리게 된다.

N×M개의 풍선에 들어있는 종이 꽃가루 개수가 주어지면, 한 개의 풍선을 선택했을 때 날릴 수 있는 꽃가루의 합 중 최댓값을 출력하는 프로그램을 만드시오.

### 제약사항
* 3 ≤ N, M ≤ 100

### 입력 / 출력 예시
| 입력 | 출력 |
| --- | --- |
| 3 | |
| 3 5 | |
| 2 1 1 2 2 | #1 10 |
| 2 2 1 2 2 | #2 26 |
| 2 2 1 1 2 | #3 40 |

### 접근 아이디어
* 각 풍선(칸)을 기준으로 델타 탐색(상하좌우)을 활용해, 그 칸의 값만큼 상하좌우로 확장하며 터지는 풍선 개수(꽃가루 합)를 계산한다.
* 모든 칸에 대해 이 값을 계산한 뒤 최댓값을 찾는 완전 탐색 문제.
* 배열의 경계를 벗어나지 않는지 확인이 필요하다.

## 4. 1210. Ladder1

### 문제
사원들은 사다리 게임으로 아이스크림 구매자를 정한다.
김 대리는 사다리를 그리고, 특정 도착점(X표시)에 도달하는 출발점 X를 찾아야 한다.
가로·세로 막대를 따라 내려가며 좌우 갈림길에서 방향을 전환한다.
100×100 리스트로 표현된 사다리('1')와 도착점('2')을 기반으로, 해당 도착점에 대응하는 출발점 X를 찾으세요.

### 제약사항
(리스트 입력: 도착점이 있는 행과 열이 주어지고, 나머지 칸은 사다리 경로를 나타내는 0/1로 구성됨)

### 입력 / 출력 예시
| 입력(요약) | 출력 |
| --- | --- |
| 100×100 리스트(0과 1로 사다리 경로 표현, '2'가 도착점) | #1 67 |

### 접근 아이디어
* 도착점(값이 2인 칸)의 위치를 찾은 후, 그 지점에서부터 사다리를 거꾸로(위쪽으로) 타고 올라가며 좌우에 '1'(가로선)이 있으면 방향을 전환한다.
* 맨 위쪽 행(0행)에 도달했을 때의 열(column) 인덱스가 출발점이 된다.
* 델타 탐색과 유사하게 "현재 위치 → 다음 위치" 갱신을 반복하는 시뮬레이션 문제.

---

## 핵심 요약
* **초심자의 회문 검사**는 문자열을 뒤집어 원본과 비교하는 기본 문자열 처리 문제다.
* **파리 퇴치**는 N×N 2차원 리스트에서 가능한 모든 M×M 부분 영역의 합을 구해 최댓값을 찾는 완전 탐색 문제로, 2차원 리스트 순회와 부분합 계산을 연습할 수 있다.
* **풍선팡**은 각 칸을 기준으로 델타 탐색(상하좌우)을 반복 적용해 터지는 풍선 수의 합을 계산하고 그 최댓값을 찾는 문제로, 경계 확인이 중요하다.
* **Ladder1**은 도착점에서 시작해 사다리를 거꾸로 타고 올라가며 좌우 갈림길에서 방향을 전환하는 시뮬레이션 문제로, 델타(방향 전환) 개념이 응용된다.
* 이 4문제는 공통적으로 **1차원/2차원 리스트 순회**, **완전 탐색(브루트포스)**, **델타를 이용한 방향 탐색**이라는 앞서 배운 개념들을 실전 문제에 적용해보는 연습이다.

## 2. 알고리즘 기본

### 알고리즘이란?
* (명) 알고리즘: 유한한 단계를 통해 **문제를 해결하기** 위한 절차나 **방법**이다. 주로 컴퓨터용어로 쓰이며, 컴퓨터가 어떤 일을 수행하기 위한 단계적 방법을 말한다.
* 간단하게 다시 말하면 어떠한 문제를 해결하기 위한 절차라고 볼 수 있다.
* 예를 들어 1부터 100까지의 합을 구하는 문제를 생각해 보자: `1 + 2 + 3 + ... + 100 = 5,050`

### 컴퓨터 분야에서 알고리즘을 표현하는 방법은 크게 세 가지
* 의사코드(슈도코드, Pseudocode)와 순서도 그리고 프로그래밍 언어

```
CalcSum(n)
sum ← 0
for i : 1 -> n
    sum ← sum + i
return sum;
```
(순서도: sum ← 0 → i ← 1 → i <= 100? → Yes: sum ← sum + i, i ← i + 1(반복) → No: print sum)

### APS 과정의 목표
* APS 과정의 목표 중의 하나는 보다 좋은 알고리즘을 이해하고 활용하는 것이다.

### 무엇이 좋은 알고리즘인가?
1. **정확성:** 얼마나 정확하게 동작하는가
2. **작업량:** 얼마나 적은 연산으로 원하는 결과를 얻어내는가
3. **메모리 사용량:** 얼마나 적은 메모리를 사용하는가
4. **단순성:** 얼마나 단순한가
5. **최적성:** 더 이상 개선할 여지없이 최적화되었는가

### 주어진 문제를 해결하기 위해 여러 개의 다양한 알고리즘이 가능
=> 어떤 알고리즘을 사용해야 하는가?

### 알고리즘의 성능 분석 필요
* 많은 문제에서 성능 분석의 기준으로 알고리즘의 작업량을 비교한다.

### 예: 1부터 100까지 합을 구하는 문제

| | 알고리즘 1 | 알고리즘 2 |
| --- | --- | --- |
| 계산 | `1 + 2 + 3 + 4 + ... + 100` | `100 × (1+100) / 2 = 5,050` |
| 결과 | 5,050 | 5,050 |
| 연산 횟수 | 100번의 연산(덧셈 100번) | 3번의 연산(덧셈 1번, 곱셈 1번, 나눗셈 1번) |

## 3. 복잡도

### 알고리즘의 작업량을 표현할 때 시간복잡도로 표현한다.

### 시간 복잡도(Time Complexity)
* 실제 걸리는 시간을 측정
* 실행되는 명령문의 개수를 계산

```python
# 알고리즘 1
def calc_sum(n):
    sum = 0        # 1번
    for i in range(1, n+1):  # n번
        sum = sum + i  # n번
    return sum
# 1 + n + 2 = 2n + 1

# 알고리즘 2
def calc_sum(n):
    return n*(n+1)//2  # 3번
# 3번의 연산
```

### 시간복잡도 ≒ 빅-오(O) 표기법

### 빅-오 표기법(Big-O Notation)
* 알고리즘이 가장 느리게 실행될 때의 성능
* 알고리즘 시간 복잡도 함수 중에서 **가장 큰 영향력**을 주는 n에 대한 항만을 표시
* **계수(Coefficient)**는 생략하여 표시

```
O(3n + 2) = O(3n) = O(n)
             최고차항(3n)만 선택   계수 3제거

O(2n² + 10n + 100) = O(n²)
O(4) = O(1)
```

### n개의 데이터를 입력 받아 저장한 후 각 데이터에 1씩 증가시킨 후 각 데이터를 화면에 출력하는 알고리즘의 시간복잡도는?
=> O(n), Why?? (데이터 입력 n번 + 증가 연산 n번 + 출력 n번 = 3n → 최고차항과 계수 제거 시 O(n))

### 다양한 시간 복잡도의 비교
* 요소 수가 증가함에 따라 각기 다른 시간복잡도의 알고리즘은 아래와 같은 연산 수를 보인다.
* 시간복잡도 순서(빠른 것부터): `O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ) < O(n!)`

### 시간복잡도별 실제 실행 시간 비교
* 요소 수(N)가 커질수록 O(n²), O(2ⁿ), O(n!) 등의 알고리즘은 실행 시간이 기하급수적으로 증가함
* 예: N=1억일 때 O(logN)은 0.1초 수준이지만, O(N²)은 2.66초, O(2ᴺ)은 사실상 계산 불가능한 수준(31,709년), O(N!)은 더욱 심각(3.17 × 10¹⁵ years)
* (1μs = 10⁻⁶초, 1ms = 10⁻³초 기준)

## 5. 1차원 리스트

### 리스트란 무엇인가
* 다양한 자료형의 요소들을 순서대로 저장할 수 있는 자료구조

### 리스트의 필요성
* 프로그램 내에서 여러 개의 변수가 필요할 때, 일일이 다른 변수명을 이용하여 자료에 접근하는 것은 매우 비효율적
* 리스트를 사용하면 하나의 선언을 통해서 둘 이상의 변수를 선언할 수 있다.
* 단순히 다수의 변수 선언을 의미하는 것이 아니라, 다수의 변수로는 하기 힘든 작업을 배열을 활용해 쉽게 할 수 있다.

```python
# 6개의 변수를 사용해야 하는 경우, 이를 리스트로 바꾸어 사용하는 예
num0 = 1
num1 = 2
num2 = 3
num3 = 4
num4 = 5
num5 = 6
# ↓ 바꾸면
nums = [1, 2, 3, 4, 5, 6]
```

### 리스트 = 1차원 리스트
* 별도의 선언 방법이 없으면 변수에 처음 값을 할당할 때 생성

```python
arr = list()
arr = []

arr = [1, 2, 3]
arr = [0] * 10
```

### 1차원 리스트의 접근
* `Arr[0] = 10` # '리스트 arr의 0번 원소에 10을 저장하라'
* `arr[idx] = 20` # '리스트 arr의 idx번 원소에 20을 저장하라'

* `int()`: 문자열이나 숫자를 정수로 변환하는 함수
* `list()`: iterable 객체를 리스트로 변환하는 함수

## 핵심 요약
* **알고리즘**은 문제를 해결하기 위한 절차이며, 좋은 알고리즘의 기준은 정확성·작업량·메모리 사용량·단순성·최적성이다.
* **시간복잡도**는 실행되는 명령문의 개수로 알고리즘의 작업량을 표현하며, **빅-오(Big-O) 표기법**은 최고차항만 남기고 계수를 생략해 가장 큰 영향력을 주는 항으로 표시한다(`O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ) < O(n!)` 순으로 느려짐).
* 시간복잡도는 최선(Ω, Best Case), 평균(Θ, Average Case), 최악(O, Worst Case)으로 구분되며, 공간복잡도는 메모리 사용량을 나타낸다.
* **1차원 리스트**는 여러 개의 변수를 하나의 자료구조로 묶어 관리할 수 있게 해주며, `arr[idx]`로 특정 위치의 원소에 접근·저장한다.
* **SWEA**에서 문제를 풀 때는 `import sys`로 `sys.stdin`을 `input.txt` 파일로 리다이렉트해 로컬(PyCharm)에서 테스트한 뒤, 제출 시에는 반드시 sys 관련 코드를 제거하고 제출해야 한다.

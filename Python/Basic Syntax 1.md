## 1. 프로그래밍과 파이썬

### 프로그램(Program)이란?
* 명령어들의 집합
* **프로그램 예시:** 친구에게 우리 집으로 오는 길을 적어주는 것 → '프로그램 작성'. 적어준 길을 순서대로 따라가는 것 → '프로그램 실행'
* 프로그램은 이처럼 몇 가지 기초 연산으로 구성됨 — 'xx 사거리에서 우회전', '두 블록 직진 후 좌회전' 등
* 컴퓨터는 더 다양한 연산 집합을 가짐 — '파일에서 첫째 줄 지워라', '네모 박스를 오른쪽으로 옮겨라' 등
* 기존 연산을 사용해 더 많은 연산을 만들 수도 있고, 이전에 사용한 연산 위에 차곡차곡 쌓아서 새로운 연산을 만들어냄

### 프로그래밍
* 문제를 해결하기 위해서 컴퓨터가 이해하고 실행할 수 있도록 프로그래밍 언어를 사용해 명령을 작성하는 과정
* 새 연산을 정의하고 조합해 유용한 작업을 수행하는 것 ⇒ "문제를 해결"하는 매우 강력한 방법
* **프로그래밍 언어:** 사람이 컴퓨터에게 명령을 전달하기 위해 사용하는 약속된 기호와 문법의 집합 (예: 파이썬(Python), C언어, 자바(Java), 자바스크립트(JavaScript) 등)
* 컴퓨터에게 작업을 지시하고 문제를 해결하는 도구

### 파이썬(Python)이란?
* 귀도 반 로썸(Guido van Rossum)이 만든 언어
* 쉽고 간결한 문법 — 읽기 쉽고 쓰기 쉬운 문법을 가지고 있어 쉽게 배우고 활용할 수 있음
* 파이썬 커뮤니티의 지원 — 세계적인 규모의 풍부한 온라인 포럼 및 커뮤니티 생태계
* 광범위한 응용 분야 — 웹 개발, 데이터 분석, AI, 자동화 스크립트 등 다양한 분야에서 사용
* 다양한 유명 기업과 기관에서 활용 — 구글, 페이스북, 넷플릭스, NASA 등과 같은 대형 IT 기업에서도 활발하게 사용. 단순히 "쉽기만 한 언어"가 아닌 현장에서도 핵심적인 역할을 담당

### 알고리즘 구현에도 유리한 Python
* **간결하고 직관적인 문법:** 복잡한 논리 구조의 알고리즘을 이해하고 구현하기 쉬움. 복잡한 자료를 선언이나 메모리 관리에 신경 쓸 필요 없이, 핵심 알고리즘 구현에만 집중할 수 있음
* **강력한 표준 라이브러리:** 다양한 알고리즘 구현에 필요한 도구를 제공
* **빠른 프로토타이핑:** 알고리즘을 빠르게 테스트하고 수정할 수 있음

### 파이썬 프로그램이 실행되는 과정
* 컴퓨터는 기계어로 소통하기 때문에 사람이 기계어를 직접 작성하기 어려움
* 인터프리터가 사용자의 명령어를 운영체제가 이해하는 언어로 바꿈 — 훨씬 더 사용하기 쉽고, 운영체제간 이식도 가능해 확장성 ↑

```
파이썬 프로그램 ↕ 파이썬 인터프리터 ↕ 운영 체제
```

### 파이썬 프로그램을 실행하는 방법

## 2. 표현식과 값

### 표현식(Expression)
* 값으로 평가될 수 있는 코드 조각

```
3 + 5  =>(평가)  8
표현식              값
```

### 값(Value)
* 표현식이 평가된 결과

### 평가(Evaluate)
* 표현식을 실행하여 값을 얻는 과정

### 문장(Statement)
* 실행 가능한 동작을 기술하는 코드
* 조건문, 반복문, 함수 정의, ... — 문장은 보통 여러 개의 표현식을 포함
* 예) `x = (3 + 5) * (2 - 1)`

## 3. 타입(Type)

### 타입이란?
* 변수나 값이 가질 수 있는 데이터의 종류를 의미
* 어떤 종류의 데이터인지, 어떻게 해석되고 처리되어야 하는지를 정의
* 타입은 2가지 요소로 이루어짐(정의적인 관점에서): 값(피연산자), 값에 적용할 수 있는 연산(연산자)

### 데이터 타입 (자세한 내용은 Data Types 챕터에서 다룸)
* **Numeric Type:** int, float, complex
* **Sequence Types:** list, tuple, range
* **Non-sequence Types:** set, dict
* **Text Sequence Type:** str
* **기타:** Boolean, None, Functions

### 타입의 중요성
* 의미 있는 연산과 결과 보장, 오류 예방과 디버깅 용이, 개발 생산성과 코드 가독성 향상

### 산술 연산자
숫자 값에 대해 기본적인 수학 연산을 수행하는 연산자

| 기호 | 연산자 |
| --- | --- |
| - | 음수 부호 |
| + | 덧셈 |
| - | 뺄셈 |
| * | 곱셈 |
| / | 나눗셈 |
| // | 정수 나눗셈(몫) |
| % | 나머지 |
| ** | 지수(거듭제곱) |

### 연산자 우선순위
식(Expression) 안에 여러 종류의 연산자가 있을 때, 어떤 순서로 연산을 수행할 지 정하는 규칙

| 우선순위 | 연산자 | 연산 |
| --- | --- | --- |
| 높음 | `**` | 지수 |
|  | `-` | 음수 부호 |
|  | `*`, `/`, `//`, `%` | 곱셈, 나눗셈, 정수 나눗셈, 나머지 |
| 낮음 | `+`, `-` | 덧셈, 뺄셈 |

**연산자 우선순위 예시**
```python
-2 ** 4    # -16
-(2 ** 4)  # -16
(-2) ** 4  # 16
```
* `**`는 단항 음수 부호(`-`)보다 우선순위가 높음. `-2 ** 4`는 `-(2 ** 4)`로 해석되어 `-16`이 됨. 괄호로 감싸 `(-2) ** 4`로 명시하면 `16`이 됨

## 4. 변수와 메모리

### 변수(Variable)
* 값(데이터)을 저장하기 위한 이름
* 특정 값을 담아두었다가 필요할 때 꺼내 쓸 수 있도록 하는 장치
* **할당문:** `degrees = 36.5` → "변수 degrees에 값 36.5를 할당했다."
* **재할당:** `degrees = 'abc'` → "변수 degrees에 값 'abc'를 재할당했다."

### 할당문
```python
variable = expression
```
1. 할당 연산자(`=`) 오른쪽에 있는 표현식을 평가해서 값(메모리 주소)을 생성
2. 값의 메모리 주소를 `=` 왼쪽에 있는 변수에 저장
   * 존재하지 않는 변수라면 → 새 변수를 생성
   * 기존에 존재했던 변수라면 → 기존 변수를 재사용해서 변수에 들어있는 메모리 주소를 변경

### 변수, 값 그리고 메모리
* 거리의 집들은 각각 자신의 주소를 가지고 있고, 이를 통해 식별할 수 있음
* 메모리의 모든 위치에는 그 위치를 고유하게 식별할 수 있는 메모리 주소가 존재
* **객체(Object):** 타입을 갖는 메모리 주소 내 값. "값이 들어있는 상자"
* 변수는 그 변수가 참조하는 객체의 메모리 주소를 가짐
* 변수 `degrees`는 값 `36.5`를 참조 — 결국 변수는 "값을 참조하기 위한 이름"

```
degrees(변수) --참조--> 491734(주소) [36.5 (타입: float, 주소: 491734)]
```

### 변수 할당 예시
```python
number = 10
double = 2 * number
print(double)  # 20

number = 5
print(double)  # 20 (재할당 이전에 계산된 값이므로 변하지 않음)
```
* `double`은 `number`가 10일 때 평가된 결과(20)를 참조하는 것이지, `number`를 실시간으로 참조하는 것이 아니므로 이후 `number`를 5로 재할당해도 `double`은 그대로 20을 유지함

## 5. Data Types (개요)

### 데이터 타입이 필요한 이유
* 값들을 구분하고, 어떻게 다뤄야 하는지를 알 수 있음
* 요리 재료마다 특정한 도구가 필요하듯이 각 데이터 타입 값들도 각자에게 적합한 도구를 가짐
* 타입을 명시적으로 지정하면 코드를 읽는 사람이 변수의 의도를 더 쉽게 이해할 수 있고, 잘못된 데이터 타입으로 인한 오류를 미리 예방

### Numeric Types: int
* 정수를 표현하는 자료형(정수 자료형)

```python
a = 10
b = 0
c = -5
```

### 진수 표현
* **2진수(binary):** `0b`
* **8진수(octal):** `0o`
* **16진수(hexadecimal):** `0x`

```python
print(0b10)  # 2
print(0o30)  # 24
print(0x10)  # 16
```

### Numeric Types: float
* 실수를 표현하는 자료형(실수 자료형)

```python
d = 3.14
e = -2.7
```

### 지수 표현 방식
* `e` 또는 `E`를 사용한 지수 표현

```python
# 314 * 0.01
number = 314e-2

# 3.14
print(number)
```

### float — 유한 정밀도
* 프로그래밍 언어에서 float는 실수에 대한 근삿값
* 컴퓨터 메모리 용량이 한정돼 있고 한 숫자에 대해 저장하는 용량이 제한 됨
* `0.6666666666666666`과 `1.6666666666666667`은 제한된 양의 메모리에 저장할 수 있는 2/3과 5/3에 가장 가까운 값

```python
print(2 / 3)  # 0.6666666666666666
print(5 / 3)  # 1.6666666666666667
```

### 실수 연산 시 주의사항 — 부동소수점 에러
* 컴퓨터는 2진수를 사용, 사람은 10진법을 사용
* 10진수 0.1은 2진수로 표현하면 `0.000110011001100110...`같이 무한대로 반복됨
* 무한대 숫자를 그대로 저장할 수 없어서 사람이 사용하는 10진법의 근삿값만 표시
* 0.1의 경우 `3602879701896397 / 2 ** 55` 이며 0.1에 가깝지만 정확히 동일하지는 않음
* 이 과정에서 예상치 못한 결과가 나타남 — 이런 증상을 **Floating point rounding error(부동소수점 에러)**라고 함

```python
a = 3.2 - 3.1
b = 1.2 - 1.1
print(a)          # 0.10000000000000009
print(b)          # 0.09999999999999987
print(a == b)     # False
```

### 부동소수점 에러 해결책
* 대표적으로 `decimal` 모듈을 사용해 부동소수점 연산의 정확성을 보장하는 방법
* 이외에도 다양한 해결 방법이 존재

```python
from decimal import Decimal
a = Decimal('3.2') - Decimal('3.1')
b = Decimal('1.2') - Decimal('1.1')
print(a)          # 0.1
print(b)          # 0.1
print(a == b)     # True
```

## 6. Sequence Types: str

### Sequence Types (개요)
* 여러 개의 값들을 순서대로 나열하여 저장하는 자료형(str, list, tuple, range)
* **특징:**
  * 순서(Sequence): 값이 순서대로 저장(정렬 X)
  * 인덱싱(Indexing): 각 값에 고유한 인덱스(번호)를 가지고 있으며, 인덱스를 사용하여 특정 위치의 값을 선택하거나 수정할 수 있음
  * 슬라이싱(Slicing): 인덱스 범위를 조절해 부분적인 값을 추출할 수 있음
  * 길이(Length): `len()` 함수를 사용하여 저장된 값의 개수(길이)를 구할 수 있음
  * 반복(Iteration): 반복문을 사용하여 저장된 값들을 반복적으로 처리할 수 있음

### str
* 문자열 타입 — 문자들의 순서가 있는 변경 불가능한 시퀀스 자료형

### 문자열 표현
* 문자열은 단일 문자나 여러 문자의 조합으로 이루어짐
* 작은따옴표(`'`) 또는 큰따옴표(`"`)로 감싸서 표현

```python
# Hello, World!
print('Hello, World!')

# str
print(type('Hello, World!'))
```

### 중첩 따옴표
* 따옴표 안에 따옴표를 표현할 경우: 작은따옴표가 들어 있는 경우는 큰따옴표로 문자열 생성, 큰따옴표가 들어 있는 경우는 작은따옴표로 문자열 생성

```python
# 문자열 안에 "큰따옴표"를 사용하려면 작은 따옴표로 묶는다.
print('문자열 안에 "큰따옴표"를 사용하려면 작은 따옴표로 묶는다.')

# 문자열 안에 '작은따옴표'를 사용하려면 큰따옴표로 묶는다.
print("문자열 안에 '작은따옴표'를 사용하려면 큰따옴표로 묶는다.")
```

### Escape Sequence(이스케이프 시퀀스)
* 역슬래시(backslash, `\`) 뒤에 특정 문자가 와서 특수한 기능을 하는 문자 조합
* 파이썬의 일반적인 문법 규칙을 잠시 탈출한다는 의미

| 예약 문자 | 내용(의미) |
| --- | --- |
| `\n` | 줄 바꿈 |
| `\t` | 탭 |
| `\\` | 백슬래시 |
| `\'` | 작은 따옴표 |
| `\"` | 큰 따옴표 |

```python
# 철수야 '안녕'
print('철수야 \'안녕\'')

# 이 다음은 엔터
# 입니다.
print('이 다음은 엔터\n입니다.')
```

### String Interpolation
* 문자열 내에 변수나 표현식을 삽입하는 방법
* **f-string:** 문자열에 `f` 또는 `F` 접두어를 붙이고 표현식을 `{expression}`으로 작성하는 문법. 문자열에 파이썬 표현식의 값을 삽입할 수 있음

```python
bugs = 'roaches'
counts = 13
area = 'living room'

# Debugging roaches 13 living room
print(f'Debugging {bugs} {counts} {area}')
```

### 문자열 시퀀스의 특징 — 인덱싱 / 슬라이싱 / 길이
```python
my_str = 'hello'

# 인덱싱
print(my_str[1])    # e

# 슬라이싱
print(my_str[2:4])   # ll

# 길이
print(len(my_str))   # 5
```

### 인덱스(index)
* 시퀀스 내의 값들에 대한 고유한 번호로, 각 값의 위치를 식별하는 데 사용되는 숫자
* 인덱싱: 인덱스를 활용해 문자열 안의 특정 문자 하나를 가져오는 것

```
"h e l l o"
index(정방향):  0  1  2  3  4
index(역방향): -5 -4 -3 -2 -1

my_str = 'hello'
print(my_str[1])  # e
```

### 슬라이싱(slicing)
* 시퀀스의 일부분을 선택하여 추출하는 작업
* 시작 인덱스와 끝 인덱스를 지정하여 해당 범위의 값을 포함하는 새로운 시퀀스를 생성

```python
my_str[2:4]    # 'll' (인덱스 2부터 3까지)
my_str[:3]     # 'hel' (처음부터 인덱스 2까지)
my_str[3:]     # 'lo' (인덱스 3부터 끝까지)
my_str[0:5:2]  # 'hlo' (0부터 4까지 2 간격으로)
my_str[::-1]   # 'olleh' (역순으로 전체 슬라이싱)
```

### 문자열은 불변(변경 불가)
```python
my_str = 'hello'
# TypeError: 'str' object does not support item assignment
my_str[1] = 'z'
```

### 주석(Comment)
* 프로그램 코드 내에 작성되는 설명이나 메모
* 인터프리터에 의해 실행되지 않음

```python
# 이것은
age = 10
# 주석입니다
print(age)

"""
여러 줄 주석
"""
```

### 주석의 목적
* 코드의 특정 부분을 설명하거나 임시로 코드를 비활성화할 때
* 코드를 이해하거나 문서화하기 위해
* 다른 개발자나 자신에게 코드의 의도나 동작을 설명하는 데 도움
* 협업하는 동료나 **나 자신을 위해서**라도 주석을 작성하는 습관을 "반드시" 익힐 것

## 핵심 요약
* **프로그래밍**은 문제 해결을 위해 프로그래밍 언어로 명령을 작성하는 과정이며, 파이썬은 간결한 문법과 강력한 표준 라이브러리로 알고리즘 구현에도 유리하다.
* **표현식(Expression)**은 값으로 평가될 수 있는 코드 조각이고, 이를 실행해 값을 얻는 과정이 **평가(Evaluate)**이며, 실행 가능한 동작을 기술하는 코드는 **문장(Statement)**이다.
* **타입(Type)**은 값의 종류와 적용 가능한 연산을 정의하며, 연산자 우선순위(`**` > 단항 `-` > `*`/`/`/`//`/`%` > `+`/`-`)를 이해해야 정확한 계산이 가능하다.
* **변수**는 값(객체)이 저장된 메모리 주소를 참조하는 이름이며, 재할당은 참조 대상만 바꿀 뿐 이전에 계산되어 저장된 다른 변수의 값에는 영향을 주지 않는다.
* 숫자 타입은 **int**(2/8/16진수 표현 가능)와 **float**(유한 정밀도로 인한 부동소수점 에러 발생 가능, `decimal` 모듈로 해결)로 나뉜다.
* **str**은 순서(Sequence)·인덱싱·슬라이싱·길이·반복 특징을 가진 불변(immutable) 시퀀스 타입이며, f-string으로 문자열 보간(String Interpolation)을 수행한다.
* 코드 품질을 위해 **PEP 8 스타일 가이드**(4칸 들여쓰기, 79자 제한, 의미 있는 변수명)와 **주석**을 습관화해야 하며, `pythontutor.com`으로 실행 과정을 시각적으로 학습할 수 있다.
